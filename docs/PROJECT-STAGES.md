## 产品和客户怎么使用

D&T 面向经营中国抖音和 TikTok Shop 菲律宾站的商家及运营团队。客户在本机工作台导入获准的商品、视频或经营资料，按任务需要连接自己的模型，使用岗位工具生成或分析内容。客户审校文字、版式和证据，商城或其他接收岗位领取与源任务、站点、商品及版本绑定的产物。商品工作流可交付主图、海报、详情页及可继续编辑的 PSD，短视频和经营分析按各岗位合同交付。

采用已有图片做本机版式、沿用确认文案、剪辑已有视频时，模型要求由任务实际需要决定。需要出站的模型动作由客户在任务中核对所选账号、模型、送出文字和费用口径后发起。实际发布、发券、改价、投放、店铺写入及真人签收有各自的授权和验收阶段。

## 这次前端审查要查到哪里

1. **账户和目录**。核对供应商、协议、地址、本机 Key 窗口、取消、到期、目录为空及查询失败。显示该账号返回的条目及能力来源。保留已认可的配置和任务上下文。
2. **三个用途**。核对目录成功后，语言与工具调用、生图、视频各能发现对应型号。用途未知时要清楚显示。所选账户和模型应确实传到任务的执行位置，错误路径应给可恢复的下一步。
3. **首页到任务**。核对恢复草稿、设置来回、按需资料、角色输入和历史任务。测试快速切换、旧回执迟到、键盘操作及不同视口。
4. **发起到取件**。分开检查确认、实际请求、等待、失败、视频状态查询、人工审校和同版文件冷取。使用独立 profile 和合成数据检查出站字段、账户与版本绑定。任务失败后保留用户材料。
5. **真人放行**。完整浏览器审查和必要的回环回归之后，再约客户在原工作台主动操作。确认实际连接、所选模型工具回合、稿件质量和取件版本分别留下回执。

| 核对点 | 实际结果 |
| --- | --- |
| 首页、导航和草稿 | 七个主要页面可打开。从商品草稿去模型连接再回来，草稿文字仍在。已有视频可进本机剪辑和转写，无须生成模型 |
| 目录查询与用途选择 | 打开连接不发目录请求，明确点「获取可用模型」后才请求。北京套餐合成目录有 22 条，显示为语言 4 个、生图 0 个、视频 0 个。选定语言可保存，手填同目录的 `wan3.0-video` 仍被服务端拒绝 |

| 自定义供应商和错误 | 只有模型编号的目录确实可以拉取，三栏过滤会隐藏这些缺能力标签的型号。拒绝读取和空目录能显示，原有其他账户的选项保留 |
| 视频入口 | 已配置视频模型后，「视频任务 → 生成新镜头」能显示所选模型，页面仍只提供配置模型、改用已有视频和稍后处理。缺少转到当前任务执行的入口 |
