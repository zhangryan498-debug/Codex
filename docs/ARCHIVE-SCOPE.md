## 本机可复现与留档边界

**可复现**：两条开发线采用同一原工作台源代码。PSD 引擎去除了旧任务目录的绝对依赖路径，沿用已安装依赖。原自带的合成图片和脚本验证素材按文件清单保留。工作区内不存在个人配置、凭据、原模型、包缓存、客户原件或用于复用真资料的原始回执。

**仅留原处**：旧项目完整 Git、历史工作数据及报告、授权供应商原始回执、带真实作品或 SKU 标识的历史采集脚本与测试、无明确可移转许可的旧 FastMoss CLI 副本，以及在用工作台的全部 profile。旧 Just One 定向试点及其本机原件绑定也留在原处。版本新旧以本仓库分支与验收索引为准，历史试点输出仅供原授权范围核对。

**迁移适配**：工作台的启动器、子进程依赖解析和本机历史素材入口已按独立目录调整。拆解历史锚点会检查由资料授权人保管的本机原件。菲律宾历史供应商库存读取继续由原工作台识别原快照，独立版可复现合成接件。OCR 源码保留，原有可执行件不入 Git。更多依赖和本机运行方式见[工作台运行说明](WORKBENCH.md)。

稳定线保留客户自行在本机确认窗输入自己的 Key 后发起的交互方式。预览线使用本机替身，开启或通过预览均不改变真人验收状态。没有配置 Git 远程仓库。冻结完整通过 **133/217**。
