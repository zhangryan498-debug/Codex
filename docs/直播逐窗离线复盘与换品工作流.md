# 直播逐窗离线复盘与换品工作流

当前只处理抖音国内与 TikTok 菲律宾的合成离线财务复盘、继续／换品／增量提案。抖音先独立验收，再开发菲律宾适配。真实开播、上架、改价、投放与店铺连接均不在本入口内。

原岗位及完整 Skill 继续使用。队列补充加载 `docs/douyin-live-ops-window-contract.json` 或 `docs/tiktok-live-ops-window-contract.json`；这些是本轮公开输入／输出契约，不能据此声称历史 Skill 全部政策已更新或核实。

## 输入与计算

每道输入显式给出平台、站点、币种、场次、当前和目标 SKU、评估时点、要求覆盖的时间窗、原始累计或窗口观测、库存、总预算／消耗／承诺，以及精确价格凭证引用。缺失值保持 null。金额使用整数最小货币单位，比例使用有理数；0 与缺失有区别。

窗口只用同场次／同 SKU／同成熟度的准确端点差或精确直接窗口。两路都有时必须一致且只记一次；重复事件去重，冲突保留所有兄弟原文并阻断提案。累计计数逐字段检查，成本／回收按声明的成本截止比较。相邻窗可相加，重复窗去重，重叠窗不合计。退款、费返和成本回收独立列示，不假定退款同时退费或回库存。

菲律宾适配只接受 PH/PHP。成熟观测必须是 confirmed_collected，pending 订单额不能填充已实收。不同暂估 basis 的规范暂估合计保持 null，按 basis 的已知候选另外保留。先检测原始事件冲突，再做结算口径筛选。PH 履约和现金流控制由输入明确给出 safe／unsafe／unknown，不引用印尼比例、历史固定天数、统一费率或 COD-only 说法。

库存使用 on_hand−reserved−safety_stock，快照已含订单，不能再扣销量；暂停后的恢复有独立回差和检查。预算扣除累计消耗与已承诺金额。未知不形成新提案，已知价格或库存等风险优先暂停。已批准换品归零目标测量基线，不继承旧 SKU ROI。增量必须有同 SKU／场次／窗口的成熟受控边际证据，并通过所有显式金额上限及最低增量利润，平均 ROI 不能代替它。

## 本地计算入口

在项目根目录，用现有虚拟环境运行；输出必须是新文件，入口不覆盖原件、不调用模型：

```powershell
& .\.venv\Scripts\python.exe -B -X utf8 scripts\review_live_window.py --platform douyin --input <离线输入.json> --catalog <实际价格host目录.json> --output <新计算结果.json>
& .\.venv\Scripts\python.exe -B -X utf8 scripts\review_live_window.py --platform tiktok-ph --input <PH离线输入.json> --catalog <PH实际价格host目录.json> --output <新计算结果.json>
```

抖音当前实现 `live_window_review_v6.py`；菲律宾当前适配 `live_window_ph_v3.py`；共同价格验证 `live_price_evidence_v2.py`。价格标签必须与原始 caller 的平台、站点、币种、SKU、数量、版本匹配，并在输入评估时点重新核对已完成原 host。历史价格凭证只有其冻结微秒区间有效，不能作为今天真实经营的报价许可。

## 模型、回执及证据

实际岗位模型由 `live_window_queue.py` 复用既有队列／岗位／Skill 运行，所有工具关闭。新题先冻结独立作者的公开数据与私有金标；4批原始回答齐全后才计算、独立评分和汇总。`accept_live_windows_v5.py` 是这一有限验收封装，不能把其固定测试时钟当真实时钟。

`accept_live_host_v6.py` 沿用原始绑定校验，从每批实际 answer 重提取 cases，核对队列原始输入、invocation、task、prompt、completion／result、原始文件哈希和实际运行信息，再与系统整数账和动作逐项比较。输出只会是 offline_proposal／blocked／rejected_model_mismatch；任何结果都带 synthetic_offline、not_authorized，执行权限始终 false。

当前回执调用 `live_window_host_v5.py`：仅对已验证换品、零增量、明确新目标空基线做保守布局提取。旧账必须有完整状态、准确成本截止、与可信原始来源一致的事件 ID 及 PH 结算 basis，且全金额逐项吻合。目标 SKU 作用域下任何非空业绩都拒绝，空／未知／冲突身份不能清除作用域；归一化保留原目标视图、来源路径与哈希，派生当前汇总明确标记。原始首答和 strict 11/12 回执不会被替换。

首轮机械分、按公开协议的规范语义复核、修复后同题回归、工程测试、静态审计、基础设施变异分别留存。变异或同题修复不得称为独立新盲测。价格 host 在本轮作为已知基础设施复用，不计新价审盲题。本工作流也未验收整场排品／话术、母语签字、实际库存同步、长时并发／断电或真实经营收益。
