# 选品供应商搜集与筛选

适用于用户要求给已有候选配货源、供应商联系方式或做供应商筛选验收。输入保留原平台、站点、商品 ID 和目标 SKU。先从原商品链接、图片或快照提取辨识点，至少说明外形、尺寸或动作、填充和回弹、颜色或包装中哪些已知。原 SKU 未明确时，记录缺口并继续找近似货源。

## 搜索与匹配

1. 用商品原名、当地叫法、规格、图片或型号找供应商。结合批发词和站点语言，例如 `grosir`、`lusin`、`dus`。印尼先找境内供货及本地补货，另列中国打样和正规进口备选。重复上架、同一联系方式或同一经营主体不能当多家独立供应商。
2. 优先读取供应商官网或商家本人发布的商品、店铺页面。聚合搜索、转发图和零售页可提供反查线索，先确认真正经营者、实际款和批发条件。只有公用平台客服或搜索结果页的记录不能算供应商联系人。
3. 分三级。A 为已确认同 SKU，至少有生产货号、可对照的包装标签或实物样品等硬证据，且规格及关键功能无冲突。B 为可询价的近似款，已有具体商品及同商家的公开商务渠道，列明已匹配和待核的要素。C 为仅线索，包括未证实批发的零售商、只有泛类目、仅聚合页或关键功能不符。外形相似不证明同模具、同配方、同工厂或原爆品供货关系。
4. 记录商品页和联系来源、查证日期、所在市场及发货地、公开电话／WhatsApp／邮件／店铺聊天、商品货号、报价币种及单位、对应变体、MOQ、是否预售。区分公开标价与实时报价；变体、单件或整箱单位不明时保留原值，避免折算。页面写的发货承诺、库存、证书和工厂身份仍待核验。

## 交付和排序

以目标 SKU 分组，通常先找每款 2–3 家可独立询价的货源；证据不足时列实际数量。按匹配度、市场履约、样品及 MOQ、报价可比性排序。只有确证标价单位、数量、运费、税费和履约路径后才比较到手成本。对高 MOQ、预售、材料宣称冲突或报价大于目标零售基准逐项标记。国内玩具资质及印尼适用准入、材料与年龄、标签、仓配按现行官方资料和该 SKU 证件核验；中国货源只能先列打样或合规本地库存候选。

可复制的询价字段为原图／目标 SKU、外壳与填充配方、尺寸克重、动作或回弹实拍、样品、阶梯价和最低起订量、包装、适用检测报告、可发货地、补货周期和次品处理。采购前比对实际样品。未经用户另行授权，只收集和准备核验问题，不发送消息、不下单。
