# 直播整场模拟离线工作流

本入口维护冻结事件前缀下的整场决策，复用原岗位、完整Skill、价审、逐窗财务、内容通知和菲律宾CPL。只产生离线模拟证据，始终scope=synthetic_offline、release_status=not_authorized、execution_authorized=false。验收结果见[本轮报告](双平台直播整场模拟离线开发与独立验收-2026-11-12.md)。

## 输入、调用与留存

1. 先按平台读取runtime-agents/<platform>-live-ops/agent.md、完整对应Skill和三份原直播模板；跨岗任务由对应lead说明委派、输入和验收。PH明确PH/PHP，不沿用印尼、其他站费率或COD假设。
2. 用新目录保存公开契约、真实输入及哈希。每场给出SKU事实、初始库存/价格与独立价证引用；每检查点给出as_of、through_seq、连接、arrivals、requests。以实际时点核验价证，不把历史通过或safe布尔值作为通行证。
3. 语义模型仅接收已到达前缀、已冻结前答及本次新内容；没有未来检查点、私有评分或实现代码。口播、字幕、视觉字段是给定观察。先冻结原答/实际CLI原件，再生成下个检查点。
4. 纯系统引擎为scripts/live_session_review_v4.py，API如下。case_prefix.steps必须是已授权披露前缀；accumulated_segments是截至该点的原始语义段列表，禁止重写历史段。

```python
from live_session_review_v4 import (
    review_prefix, save_checkpoint, verify_checkpoint, resume_checkpoint,
)

# 变量从明确文件读取；catalog为当前平台实际价审目录，rule_pack为冻结规则包。
result = review_prefix(case_prefix, accumulated_segments, catalog, rule_pack)
save_checkpoint(new_checkpoint_path, case_prefix, accumulated_segments, catalog, rule_pack)
verified = verify_checkpoint(new_checkpoint_path, case_prefix, accumulated_segments, catalog, rule_pack)
# 后续新Python进程用扩展前缀恢复；输入或依赖变更会拒绝旧快照。
continued = resume_checkpoint(new_checkpoint_path, extended_prefix, extended_segments, catalog, rule_pack)
```

save仅新建文件；不覆盖旧快照。代码、来源、游标或哈希失配不得伪造修复成功，应保留失败原件并新版本处理。新部署路径的快照依赖绑定新路径，不能拿原执行路径的ready JSON为迁址运行背书。运行Python时使用-B，保持旧证据不因缓存修改。

5. 保留模型原答、JSON事件、结果/收尾、实际调用元数据、每次输入、队列和完整来源索引。模型语义、系统机械投影、独立金标与实际恢复分别报告；不把schema通过或模型/系统一致当独立语义正确。
6. 使用原三模板组织排品、给定脚本/观察及复盘。null保留未知；未提供的流量、转化、GPM、真实退款率、人工结论保持缺失。

## 必须保留的状态语义

日记只按权威正序列的连续前缀推进。重复去重、缺序缓冲、后补可恢复；身份或序列冲突和真实invalid在本版本粘滞拦截。上层当前账未知时，不能把known_validated_prefix或candidate_branch_evidence放进当前成熟账。候选分支必须保留且排除规范账，不能静默挑一个冲突赢家。

订单额、实收、待收、退款、成本回收、回库各记各的；退款不自动回库，履约不自动已收，收播不自动财务成熟。已知0、未知null和not_observed分开。未知总成本可以保留已知小计，但不得计算完整成熟利润。绝对库存快照按覆盖水位合并，不能重扣已覆盖订单。

每个目标SKU独立核价证、数量、版本、库存、内容与限制。预览中的当前价主张随活动新版本重新比较；无价格主张的安全预览可在其他条件成立时跨版本使用。过期/未证明价证和已绑定价格数值不符分别诊断，但均不能凭未证信息放行。换品不洗掉当前违规、通知或缺口。

安全暂停、收播和复盘与销售放行分开；终止或已收播场次不复活。普通通知需要匹配原事件、整改及解除证据；断连恢复不虚构平台解除。CPL依原冻结官方适用范围区分视频/LIVE，不把视频阈值套给LIVE，也不把可能处置写成必然。

## 已完成证据的复核

原始prepare/run、旧队列及其uncertain任务不再启动。中断恢复凭证保留unknown退出，不造result/completion。两个最终combined原答、v1/v4 host、作者矩阵与来源链均在[导航](直播整场模拟验收导航-2026-11-12.md)。

如需新的确定性复核，先核对原路径、readiness和全部来源哈希，再用原执行根目录下rehost_live_session_evidence_v4.py写入全新输出目录；它只重放既有原答，不调模型。归档镜像中的helper因自身路径不在旧ready map中会拒绝，不应绕过；迁址需新来源审核。现有最终回执已完整生成，日常查阅不需要再次重放。

本轮没有真实经营验证授权。后续真实媒体、母语审核、完整创作质量和平台实盘必须各自定义验收，不把本轮合成控制流程外推为上线完成。
