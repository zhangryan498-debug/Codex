# 双平台选品数据使用规范（2026-11-08）

已实测：Just One抖音搜索/api/douyin-ec/search-item-list/v1，解析data.summary_promotions.base_model；product_info.sale_axis为30天日销量，month_sale为独立口径；marketing_info.price_desc.price.origin为分，须结合展示integer/decimal核对；promotion_info.cooper_author_num是合作达人，不是同行卖家数。详情total_sales与搜索月销有冲突，不拼接。

FastMoss原生MCP用于TK印尼product_search（filter.keywords/region）、product_sales_trend、product_overview、product_creator_analysis；调用前按实时工具schema构造参数。先查credit_usage_summary，只在授权额度内查询。7/28/90天汇总与日序列分别保存，按返回实际日期统计；最新0值若疑似未更新不得判下滑。

FastMoss OpenAPI 已配置，可按任务使用 REST 端点。调用前按官方 REST 字段和独立用量核对，记录来源为 OpenAPI。 [OpenAPI 调用与实测记录](Codex迁移运行说明.md#fastmoss-openapi)

价格：IDR本地字符串Rp22.938→22938 IDR，逗号为小数符；JSON number 22.94不自动删点或乘1000。保存原文、类型、币种和转换依据；floor/ceiling与展示不一致时优先明确展示字段并标注异常，不据冲突值算利润。

覆盖结论：足够双平台初筛，未完整证明抖音90天、TK五站全部能力、同款竞争份额、精确供应商与联系方式、履约合规。不得宣称所有选品需求全部通过。空结果不等于无需求；关键词首屏不等于全类目榜单；达人0不等于无广告。第三方数据不冒充后台成交。

每轮3–5款研究候选，分平台与币种；计算末7天与前7天从同一日序列重算，保留实际日期。评估时效/节点、标品可比价、竞争证据与长期性，未知明确列出。不用虚构综合分填补缺口。供应商要匹配规格、公开商务渠道与报价日期，竞品店铺不默认厂家；没有采购成本不报真实利润。
