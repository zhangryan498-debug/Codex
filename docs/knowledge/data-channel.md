# D&T 数据通道与证据使用边界

本页从旧工作区的《D&T 数据通道》整理出可在独立工作区重用的证据口径。涉及旧版测试、具体配置、额度或历史账号资料时，回到原授权位置核对。岗位从当前任务的授权范围和验收要求出发。

## 先识别资料来自哪里

| 类型 | 适用范围 | 使用条件 |
|---|---|---|
| 本机资料和已批准的历史导出 | 离线复核、开发、自测和回归 | 记录来源、采集时间、站点、对象、版本和许可。合成样本明示为模拟 |
| 已授权的公开或第三方只读接口 | 发现线索、对照公开商品或作品和补全有契约的字段 | 先核站点、接口契约、请求费用、缓存或延迟和使用权限。无授权、费用未知、路径不适用时使用已有资料或标缺口 |
| 官方后台或用户授权的业务导出 | 同店同品同窗的实况核验及经营结论 | 仅在阶段与权限满足时用。当前工作区默认离线。价格、库存、上架、投放等真实动作分别按各岗位门禁 |

## 共同口径

- 比较两份记录前先对齐平台与站点、店铺、商品或 SKU、地区、入场与统计窗口、时区、指标分母。作品状态、挂链和目标商品身份分别核。估算、区间、实际值、实际零和未知分别保存。
- 保留字段来源、采集时点、是否回填或晚到、筛选和去重方式；合同中未定义的字段按未知处理。退款与 COD 适用成熟窗；无法对齐条件的价格、库存和成交只作线索。
- 岗位交接固定到同一任务、同一资料版本和该级权限。接件人可独立读取当前版本，错站、错品、错版本和来源冲突向送件岗位回报。
- 本机回归使用脱敏或明确合成资料。真实业务或第三方接口方面的结论以当前授权、适用契约和实证为准。冻结范围及现有工作台证据见 [项目验收索引](../acceptance/acceptance-index.md)。

## 岗位对照

- 竞品、选品和拆解使用公开或获准资料定位来源。商城、活动和投放涉及实际库存、成交、费用、退款、报价及平台操作时，核合格的授权业务来源与相应门禁。
- 负责人汇总口径、证据版本和依赖，保留未验证项及责任方。影视或视觉素材还需保留用途授权和人工审校口径。
