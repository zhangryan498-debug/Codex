## 1. 一句话本质差异

| | 抖音 | TikTok（东南亚） |
|---|---|---|
| 商业本质 | **国内货架+兴趣双轮的综合电商**，平台已进入"收租"阶段 | **跨境的纯内容电商**，靠本地达人分销与 COD 履约驱动 |
| 钱的来源 | 广告货币化率上行 + 品牌店播替代达人 | 佣金 + 履约差价，靠单量和达人铺量取胜 |
| 核心矛盾 | 流量成本（投流税 15%-30%）vs 商户利润 | 履约成本 + 退货率 vs 客单价天花板 |
| 一句话打法 | 抢占搜索与商城心智，用全域推广守住 ROI | 用低客单小件 + 高佣金铺达人，用本地化内容打透 |

## 2. 流量结构

### 抖音
- **三个流量池已被统一调度**：M1（内容）/ M2（交易）/ M3（广告）。2025 年 4 月千川并入抖音电商后，流量统一归电商分配。
- **全域推广**：以"商品整体支付 ROI"为优化目标，**不区分自然和付费流量**——"自然流量"在算法账本里已被注销。商家推广方式在 2025 年 5 月统一切换为全域推广。
- **货架（商城）占比 40%–50%**，但含大量内容场导流。**剔除内容导流后，用户主动在商城搜索下单仅占大盘约 10%**（2025Q3，较 2025 年前的 7% 仅提升几个百分点）。这是全队必须知道的"口径幻象"。
- **大货架构成**：商品卡（纯图文商品页成交，占大货架近一半）+ 非商品卡（内容场引流至货架完成）。入口为商城、搜索、店铺/橱窗、其他四类。
- **日均搜索量突破 4 亿**，已成中国第二大搜索引擎。搜索流量转化率约为推荐流量的 **12 倍**（高客单、定制、2B 尤甚）。
- **店播已是主力**：2025H1 店播占 52%、达人带货约 30%、货架约 40%（"433"格局）。618 期间破千万直播间中店播占 68.5%。
- **头部达人贡献降至 9%**，中小达人（<100 万粉）贡献达人带货成交额超 85%。
- **电商 VV 占比** 2024 年约 15% → 2025 年约 16%。
- 商家自播 + 货架场景合计占比已升至 70% 左右。

### TikTok（东南亚）
- **内容驱动是唯一主引擎**：TikTok Shop 本质是"内容电商"，货架心智远未建立，商品卡曝光主要依赖短视频/直播引流。
- **达人分销（Affiliate）是履约主引擎**：TikTok 精选联盟 + 本地达人网络，而非平台自营货架。东南亚直播渗透率低于国内，短视频带货是主战场。
- **联盟生态比国内分散**：本地网红批量铺量，头部达人不集中，中腰部与尾部达人贡献更大。
- **TikTok Ads Manager** 承担广告投放，与联盟原生内容（Spark Ads 等）配合。
- 平台正在强化**本地化要求**，并已有多次上调本地卖家佣金。

## 3. 成本与利润结构（选品/投手的核心依据）

### 抖音
- 平台技术服务费：按类目 0.6% 保留，其余可通过**商品卡免佣**活动减免（需报名）。
- **投流税**：广告投流费用占营收比例上限，大部分类目 **15%**，美妆类目 **30%**。超出部分在企业所得税下抵扣减少 → 直接抬高实际投流成本。⚠️ 做利润模型必须先扣这层。
- 达人分销佣金（精选联盟）：基础佣金建议 **10% 以上**，阶梯升佣（100 单后 20%+）是冲量标准打法。
- 履约：国内仓，次日达/隔日达为主。**退货率与"仅退款"是利润杀手**，抖音官方已承认退货率是平台短板指标。
- 物流成本低，所以能吃低客单，但利润薄。

### TikTok（东南亚）
- **平台佣金**：印尼 5%–8%（本土店）、泰国 6.42%–9.63%、越南 5%–8%（含交易手续费口径差异）。⚠️ 2026 年 2 月印尼时尚类目从 2% 涨到 3%、美妆从 3% 涨到 4%，2026 年 6 月又加码本地化要求 → **佣金结构在持续变动，必须按月复核**。
- **达人佣金行业区间 ⚠️**：印尼 10%–20%、泰国 12%–25%、越南 10%–18%。分层参考：头部（>50 万粉）20%–25%、中腰部（5–50 万）12%–18%、尾部（1–5 万）10%–15%。**佣金超过 25% 在低客单市场基本不赚钱**。
- **COD 是双刃剑**：印尼站 COD 订单占比约 68%，但 COD 订单退货率 **35%–45%**（预付单仅 12%）。**签收率连续两周 <60% 将限制短视频挂车功能**。
- 客单价天花板：印尼 $5–15、越南 $8–20、泰国 $10–30。TikTok 东南亚 GMV 最大市场印尼的客单价只有 5–15 美元。
- **必须按站差异化定价**：印尼要求更高佣金比例（绝对值低），泰国同样 20% 佣金绝对值高 3 倍 → 不能把美区/泰区佣金逻辑套到印尼。
- 物流：单票成本约 ¥8–12（≤500g），时效 3–7 天；COD 附加费约 $0.3/单。
- **COD 必须本地认证仓发货**，用国内直发虚拟单 = 物流欺诈，订单金额 3 倍罚款，最高 $500。
- **回款周期长**：COD 签收后 15 天，预付 7 天；整体回款约 12–18 天（含退货确认期）。需准备 **≥3 个月运营成本的现金流缓冲**。
- **印尼合规**：需完成 API-UD 进口商登记方可清关；本土店保证金约 2000 万印尼卢比（≈$1300）；中国主体直连保证金门槛较低但**无法使用 COD**。
- 印尼站综合退货率 8%–15%（COD 更高）。⚠️ 关键成本陷阱：**退货只退买家全款，达人佣金与平台费不退回**——利润表必须扣预估退货率，否则"看着赚钱实际亏"。

### 成本速算公式
```
抖音：净利 = 售价 - 货成本 - 技术服务费 - 投流费(受投流税上限约束) - 达人佣金 - 退货/仅退款损耗
TikTok：净利 = 售价 × 实际签收率 - 采购 - 平台佣金 - 物流 - 达人佣金 - COD附加费
```

## 7. 合规红线（两平台通用 + 平台特有）

**通用红线（务必全员掌握）**
1. 虚假宣传 / 材质不符 → 店铺扣分（抖音 -5 至 -20 分，TikTok 约 -2 分/次），累计封禁或暂停结算。
2. 诱导好评（返图赠券、强制捆绑销售）→ 平台处罚（TikTok 罚款 $50 起）。
3. 盗用素材、AI 换脸 → 限流；批量克隆同一脚本 → 限流。
4. 商品描述与实物不符 → 买家投诉仲裁，赔付标准可达订单金额 150%。
5. 虚假发货 / 物流信息 48 小时无更新 → 判定虚假发货，扣分至停权。

**抖音特有**
- 投流税：投流费用占营收比例上限（多数类目 15%，美妆 30%）。
- 电商内容加载率有上限（刷 100 个视频约见 9–12 条电商内容），超载伤体验、伤流量。
- 禁止强制捆绑销售、虚假好评。

**TikTok 特有**
- COD 必须本地认证仓发货（3 倍罚款，最高 $500）。
- COD 异常率监控：连续 7 天拒收率 >45% 限制商品曝光；单日拒收率 >30% 持续 2 天自动暂停推流 72 小时。
- 连续 3 单虚假发货冻结账户且不退已结佣。
- 印尼 API-UD 进口商登记要求；各国类目认证（化妆品/食品/电器）需前置完成。
- 保证金与本地主体资质（中国主体直连无法使用 COD）。

## 8. 核心指标口径

### 抖音
| 指标 | 口径要点 |
|---|---|
| 支付 GMV | 平台口径，与结算 GMV 不同（2026 年字节已将结算 GMV 列为重点考核） |
| 全域 ROI | 支付 ROI，优化目标含自然+付费，不可与纯广告 ROI 混用 |
| 商品信息质量分 | **<85 分有负向流量影响**，目标保持 90+ |
| 好商品门槛 | 销量 >10 单、好评率 ≥85%（目标 90%）、详细评价 ≥10 条 |
| 商品卡 GMV | 占大货架近一半，是货架核心战场 |
| 搜索流量 | 日均搜索 4 亿次，加热搜词可带来约 +20% 搜索流量 |
| 商家自播占比 | 618 破千万直播间中店播占 68.5% |

### TikTok（东南亚）
| 指标 | 口径要点 |
|---|---|
| GMV | 按站分口径（印尼/越南/泰国费率不同） |
| 实际签收率 | **COD 模式下的真实 GMV 口径**，必须乘到 GMV 上 |
| ROI | 扣除退货后计算；达人佣金按下单 GMV 计，不按签收额计 |
| 退款/拒收率 | 印尼综合 8%–15%，COD 单 35%–45%；超阈值触发限流 ⚠️ **本行与 L54 存在口径冲突，见下方「签收率口径冲突」** |
| 佣金成本率 | 平台佣金 + 达人佣金 + 广告佣金（若投流）需分轨核算 |
| 现金流覆盖月数 | COD 模式需 ≥3 个月 |

#### 签收率口径冲突（2026-11-05 核算发现，**已裁定：挂起，等待店铺后台实数**）

本文件两处数据可推出两个互斥的「实际签收率」，差 **19.54 个百分点**：

| 来源 | 推导式 | 结果 | 性质 |
|---|---|---|---|
| **L152**「印尼综合 8%–15%」 | 1 − 综合退款率 | 0.85 – 0.92，中值 **0.885** | 「综合退款率」派生量 |
| **L54**「COD 占比 68%，COD 退货 35%–45%（预付 12%）」 | 1 − [0.68×0.40 + 0.32×0.12] | **0.6896**（区间 0.6556–0.7236） | COD 加权 |

**⚠️ 2026-11-05 业务裁定（负责人决定）：两个来源样本不同期，都不可靠。**
L152 的「综合」到底指预付单还是全站、L54 的 COD 占比与退货率是否为同期样本，**均无法从现有材料判定**，
因此 **0.885 与 0.6896 都不作为定稿值**。处置规则：

- **站内相对比较不受影响**：签收率是站内统一乘数，不改变站内商品排序，
  「谁卖得好、谁价格高、类目结构如何」这类结论**继续可用**。
- **绝对 GMV / 利润 / 定价结论一律挂起**：不输出基于任一口径的净利与定价底线结论；
  报告中如需展示，必须并列两口径并标注 **「±19.54pct 不确定性，口径未定稿」**。
- **临时工作口径（占位，非定稿）**：必须给一个中间数时统一用 **0.6896**（保守值），
  并在同一行标注「口径未定稿，待 L3 店铺后台实数替换」。
- **关闭条件**：拿到**店铺后台当期实际签收率**（Tokopedia / 卖家中心）→ 替换本节全部数值。
  在此之前，本节任何数字**不得**作为定价、利润测算或对外报价依据。
- **责任岗位**：TikTok 出海事业部负责人裁定 + 店铺运营取数（见 `docs/acceptance/acceptance-index.md`）。

## 9. 给全队的三条硬规则

1. **同一岗位在两平台的打法不同，不要套用**。抖音选品看"内容爆点 + 千川承接性"；TikTok 选品看"跨境物流属性 + 达人可讲性 + 类目认证门槛 + 退货率预估"。
2. **算利润先扣退货/拒收，再谈佣金**。TikTok COD 场景下这是最常见的亏损来源；抖音场景下要扣"仅退款"损耗。
3. **平台规则和费率在变**。TikTok 佣金 2026 年已多次上调，抖音投流税是新增约束。所有费率类结论必须标注来源与时点，Agent 输出时给出"需复核"的提示。
