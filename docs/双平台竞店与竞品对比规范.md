# 双平台竞店与竞品对比规范

每个平台按店铺对店铺、商品对商品分别交付。优先选同站、同用途、相近价格带且店铺和商品 ID 均不同的对象，写清同类对标与可确认同款的区别。记录接口、抓取日期、实际统计窗口、币种与样本边界。第三方估算、商品资料、买家反馈、页面观察和推断分别标记。

报告最前或最后必须给出明确结论与建议：本样本哪家店更值得对标、优势证据是什么；哪个产品更值得优先选、商业竞争力与质量线索各是什么。店铺整体经营优势、短期爆发和单个商品机会可以分开选择，避免用单品数据冒充全店排名。缺少质量证据时仍交付商业优先级，同时明确质量胜负未证实，不以编造评分填补。

将商品平台、站点及稳定商品 ID 与最新选品报告的高潜候选逐一匹配，列出精确命中、同方向近似和未命中。精确命中后调用既有供应商清单，直接列供应商、公开商务联系方式、商品/联系来源、报价单位及 MOQ、匹配分级与差异。相似商品只能引用同方向货源作参考，不得继承精确 ID 命中或已确认同 SKU；同一商家跨候选重复出现要去重计数。供应商资料与本轮重新核对的结果分列，库存、报价、同款及履约未确认则如实标注，不自动外联。

- **店铺身份和层级**：并列展示平台店型、品牌归属、营业主体类型及经营/履约模式。品牌、旗舰、自营、个体各自需平台标识、主体资质或可追溯证据。`local_shop` 只说明本地店分类，`is_fully_managed=false` 只说明非全托管；名称和关联达人都不证明主体身份。官方店铺等级与样本相对规模分列。相对规模可比较在售商品、同窗销量、GMV 与主品集中度，说明基准。评分不得换算为层级。
- **店铺规模及价格**：按商品 ID 去重。列目录覆盖、动销、同窗销量、GMV 与渠道份额。订单客单用同窗 GMV 除以订单数，缺订单数则留空；同窗 GMV 除以商品销量是估算件均金额。目录标价均值另列样本量、选择方式、范围和中位数，不能代表全店成交或订单客单。
- **商品与 SKU**：分别列价格区间、SKU 标价、成交样本字段及件均金额。注意单只、套装、引流和折扣口径，规格不齐不直接比价。按用户当前要求，以商详材质描述、图片 OCR 和评价关键词完成方向性的质量比较，不以买样作为完成这一步的前提。区分商家材质声明、买家材质称谓与分析推断，不能把这些写成已验证的真实成分、安全或耐用性。图文和已购 SKU 的尺寸冲突需明确列出。
- **评价**：分列总量、评分或好评率、取样时间、星级分布和有正文数。至少按质量、使用体验、规格包装和履约归纳，说明小样本和空评比例。按评价 ID 去重，每条评价对同一个关键词最多贡献一次，保留否定语境、混合评价和原文。中印尼语义归并要可追溯；激励评价标记与展示样本偏向需要明示。空响应记为该通道未取回正文，不能覆盖另一通道已取回的正文，也不能记作零评价。评论投诉是样本风险线索，不能推算真实瑕疵或退货率。
- **视觉**：说明实读图片和页面范围。用主体识别、信息层级、规格可读性、承诺及证据对应、移动端清晰度比较。只能看到封面时只评主图，不给整页评分。复用相同素材不能证明两款同厂、同材质或同质。不能把道具文字当商品规格。

验收至少覆盖两店及两品、各字段证据或明确缺口、能复算的数字、以及对选品、内容或运营可验证的建议。区分已证明的分析能力与采集仍缺的字段。在线调用先核当前契约与授权额度，限量取样；余额、授权或工具报错时保留返回码，并用已有可核证据补全。

材质和评价专项读取 `docs/商详材质与评价词云工作流.md`。脚本、OCR 和关键词规则随证据一起复算；词云只作辅助，结论同时引用准确条数与原文，不能按云图字号跨商品比较质量。
