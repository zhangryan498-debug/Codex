# 直播品牌背书视觉一致性静默规则 v2

生效口径：Ryan 于2026-11-14明确要求“画面出现品牌一致就先按品牌一致静默处理，规则放宽”。这是项目提醒策略，不是平台新条款或法律授权证明。

## 后续检测规则

1. 先结合直播间标题、品牌贴片、可见账号/店铺标识等画面线索，与同窗口播背书品牌对应。不要求标题和贴片同时存在，但画面线索必须足以判定对应关系；OCR/ASR候选不能自行冒充已确认视觉观察。
2. 画面与口播品牌一致、有足够且同源同窗的观察依据时，对**仅由品牌对应/授权核查引起的提醒静默**，不逐一索取授权凭证，不在日常报告中反复追问或提示“请补授权”。内部保留视觉一致、授权法律证据未知这两个独立状态。
3. 品牌不一致、画面信息不足、识别冲突、时间/素材/站点错绑均保留核对提示。缺证据不认定未授权、不假称已授权。
4. 导流、虚假价格、医疗功效、已出现具体假货证据等独立风险不因品牌一致而静默。混合风险提示不能整体删除；只静默有明确品牌单一范围、且该提示没有其他独立风险的部分。独立风险字段未知或非原生布尔false时，不进入该静默分支。
5. 视觉一致不证明商品正品、全部声称真实或价格合格。引用/否定/普通叙述仍做语境复核；不同数字先核商品、对象、条件、单位和同一断言，不能由同屏数字直接报价格冲突。

## 已落地的纯后处理入口

`scripts/live_brand_visual_silence_v2.py` 的 `evaluate(scope, observation, alerts)` 是无I/O、无网络、无模型的元数据函数。现行直播违规工作流应在候选识别和必要语境复核之后、生成用户提醒之前调用它。旧冻结入口和原词形候选仍保留，不能直接把它们当作当前最终品牌提醒。

scope须带视频SHA-256、平台/地区和目标区间。observation须同一视频/站点且覆盖该区间，来自本机人审或另经验证的本机观察流程，显式记录visual_status、visual_observed、speech_observed和relation。函数本身不证明输入观察真实，不替代OCR/ASR感知质量验收。当前录屏观察由Ryan提供，没有将音画或转写送给在线模型。

alert的scope仅为`brand_identity_authorization`且`independent_risk is False`，在充分品牌一致分支才返回silent；其他scope和独立风险保留。输入记录不改写，函数不给经营执行权，不评估或覆盖既有价审。法律授权不由该视觉规则判定，也不再作为本轮视觉一致性静默的补证前置条件。

## 版本与验证范围

旧CN有限词形候选没有视觉品牌一致的静默分支。v2在其后增加明确范围的静默层，保留原始候选、Ryan原标签与每次复检，不回填旧首分/金标。原先拟稿v1的“视觉通过、授权单列”现由v2落实为用户提醒静默，v1记录保留追溯。

16个冻结自造逻辑对照首次16/16：品牌一致且授权未知、品牌不一致、画面不足/冲突、关系未知、错视频/错站/错时间、字符串布尔、独立风险及其他假货证据、未知独立风险状态、未验证OCR、整数0不能当原生false。它们是确定性回归，不是独立模型新盲测或真实音画准确率。

方法可用于三地的品牌视觉对应检查，但平台规则、身份条件、生效日及处置仍逐站核验。本次实际录屏是抖音国内，不移植印尼或菲律宾处罚阈值。价格/成本/券分摊资料未知仍拦截真实执行；不接店铺、不付费、不外传素材、不改变窗口设置。
