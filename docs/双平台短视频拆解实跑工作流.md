# 双平台短视频拆解实跑工作流

更新日期：2026-11-09，V4本地GPU语音复验。适用抖音国内和TikTok印尼当前玩具研究；原私有Skill正文和模板本轮未修改。最新研究档案为 `docs/provider-evidence/turbo-upgrade-2026-11-09/`；V3素材与接口基线为 `docs/provider-evidence/video-reacceptance-2026-11-09/`，前轮视觉研究保留在 `video-teardown-2026-11-09/`。本工作流记录已经验证的执行路径及尚未通过的能力。

用户最新口径：**抖音发布作品只需验证关联目标商品ID；具体颜色/规格SKU不作为通过前提。** promotion_id须按已核映射转到product_id；未取得变体ID只记录为补充信息。原发布作品的目标商品ID仍未证，因此本次不会仅因标准调整而签通过。详见 `docs/短视频拆解验收口径与语音核验说明.md`。

最新前置门：先核本条作品是否有商品入口，再查目标商品ID。原三玩具片未得实际锚点时不继续盲采；无入口/未确认的仍可作内容结构样本。新用户汽车支架对照通过 `aweme_detail.anchor_info.extra` 的内嵌JSON取得真实商品和推广ID及跳转schema，证明空promotions/anchors不等于无挂车。须用同一作品的商品行与schema核对；`status.with_goods`只作线索，`item_id`不可误当商品ID。按 `scripts/inspect_douyin_product_entry.py` 的已验分支复用，其他形态留unknown，不猜字段。两自动成片路径另见 `docs/双平台短视频自动成片双路径工作流.md`。

## V4新增：本地Turbo GPU转写

Large-v3-turbo固定模型与CUDA运行库已落项目，并完成真实推理。正式调用及恢复见 `docs/本地语音GPU运行说明.md`，入口为 `scripts/transcribe_local_video.py`；岗位可直接使用，不依赖当前聊天的直接音频输入能力。

6条发布原片与1条商详演示的同源16kHz音轨共211.019秒，全部在RTX3070上以CUDA/int8_float16完成；逐条推理合计6.312秒，加载2.328秒，批次回执9.188秒。模型校验、下载、采帧和岗位分析不计入该批次耗时。显存加载后1726MiB、逐条结束1839—1840MiB，为整卡采样值，不是模型独占峰值或并发承诺。单条独立CLI也已通过，源文件与旧base稿哈希关联、时间戳检查均通过。

Turbo改善了中文长句、商详演示和TK商品/促单语义；A开头仍无可靠识别，C材质仍TP2对画面tpr，TK B开头spisi、TK C尾句等继续限定。TK C的26k只作为自动近似价格候选，不改写成截图Rp26.100的精确口播。模型更大不代表所有片段改善；未做人工听审，也没有独立真值准确率。

本轮只本地处理已有素材，新平台调用0、媒体上传0；系统驱动与PATH未改。Social Account Doctor继续不装。抖音发布作品到两目标商品ID仍未补出；变体SKU不作为该缺口。

## 新验证的取片与身份路径

TK作品Web详情的playAddr为空时，保留该回执，从同作品作者字段取得secUid；使用已有获准Just One `tiktok/get-user-post/v1`，首屏cursor=0，后续只用上次max_cursor，有限翻页精确匹配aweme_id及作者身份。命中后从该作品的 `video.play_addr.url_list` 下载普通CDN资源，并过FFmpeg视频流/实际帧门槛。请求MOST_POPULAR在本轮不保证按播放排序，置顶项也会打乱时间顺序；不得据请求名宣称取到最热门全量作品。某账号有限页未命中时记未取得，不无限翻页。

抖音候选账号只同名时，补 `douyin/get-user-detail/v3` 的secUid查询；本轮店铺硬关联在 `/response/data/user/card_entries/0/card_data`，须解码嵌套JSON后读shop_id。再与商品搜索/店铺商品中的product与promotion映射对应。`douyin/get-user-video-list/v1` 的作品仍须逐条匹配商品锚点；同店账号并不保证每个作品都卖目标商品。

商品SKU使用 `douyin-ec/get-item-sku-info/v2`，参数itemId。实际变体在data.skus，保留id/productId/shopId、规格/包装数量/图片和来源指针；官方提示V2可能不完整。该响应的promotion_h5也可能有商品演示：本轮B的 `head_figure_data.media_list[0].content_list[0].url` 真正可下载，A的评论空video_info不算资源。按source_kind=merchant_product_demo记录，发布作品和具体变体ID为空时不猜。

Just One文档： [TK作者作品](https://docs.justoneapi.com/zh/api/tiktok/user-published-posts-v1)、[抖音用户资料](https://docs.justoneapi.com/zh/api/douyin-tiktok-china/user-profile-v3)、[抖音SKU V2](https://docs.justoneapi.com/zh/api/douyin-e-commerce/product-sku-info-v2)。文档存在不等于每次取到所需字段，仍以实际回执验收。

## 取得并验证素材

先运行岗位Skill的根路径解析器并读取完整Skill、三模板、平台模型与数据渠道。复用已归档商品和作品ID，避免为重写报告重复取数。

实际取数按端点记录状态：Just One `douyin/get-video-detail/v2` 使用videoId；`tiktok/get-post-detail/v1` 使用postId。按返回检查play_addr、字幕及资源类型。FastMoss的列表/详情可以提供线索和估算，不承诺返回可播放资源。某接口601、空脚本、空playAddr各自记录，不能把单点失败外推整个服务。

下载完成后核验容器和实际媒体流。工具成功退出不等于视频到手。只有音频时标audio_only，不计发布视频；静态封面也不能代替原片。WAF、签名或登录阻拦按缺口记录，本轮未使用cookies、代理或风控绕过。

保留平台/站点、作品与账号ID、商品ID及SKU关联级别、资源类型、源API缓存JSON pointer、精确抓取时间、原文件SHA256。字幕ASR、音轨和商详资源各有自己的身份，禁止拼接不同资源后认作同一条作品。

## 本地处理与观察

在项目根目录执行：

```powershell
.\.venv\Scripts\python.exe -m pip install -r interface/video-analysis-requirements.lock.txt
.\.venv\Scripts\python.exe scripts/prepare_video_evidence.py --video '本地原片.mp4' --output-dir 'work/video-evidence/样本' --interval 1
.\.venv\Scripts\python.exe -m unittest discover -s scripts -p test_video_evidence.py
```

`prepare_video_evidence.py`仅处理本地文件，验证视频流与时长，保留FFmpeg probe、定时帧及哈希、接触表、可用音轨和evidence.json。需要更细动作时用0.5秒或按段补帧；240个计划采样点以上要求先切段。脚本不理解画面、不上传素材、不调用平台或模型。当前Windows字体路径为微软雅黑，移到其他系统需调整。

人工查看接触表及必要大图；保留每条观察的实际时间点与帧hash。逐秒抽样不等于连续观看，不得推测亚秒回弹耗时、片段静音、精确剪辑点或完整口播。

本地ASR版本在 `interface/video-asr-requirements.lock.txt`，GPU库和模型分别用 `video-gpu-requirements.lock.txt`、`video-asr-model.lock.json` 固定。运行 `scripts/transcribe_local_video.py --audio '已提取audio-16k.wav' --language zh --output-dir '新的输出目录'`，印尼语改id；详见本地GPU说明。faster-whisper1.2.1与PyAV19出现metadata_errors兼容错误，保持av18.1.0。每次保留源hash、原稿和句词时间；强制language的概率1不是质量分。机器文本可支持有边界的语义研究，不能自动认证精确口播、实物材质或检测合格。

## 按原岗位分析并分层验收

按八段完成首3秒、内容结构、要素、承接、量化口径、改写、风险、归档；缺少的声音或画面明确空缺，不从标题补台词。TK附原语/中文、站点、达人属性、本地化四档、所需物料与COD信息状态；现行支付/履约规则未核实不写确定结论。

可见事实、机制假设、真实经营效果分列。全0播放/粉丝可能是占位，不作分母。FastMoss28日商品贡献不与窗口不明的播放量计算成交转化；不同列表与详情快照不混算增长。均播不是中位数；无同账号基线称对标样本。

阶段分别验收：①元数据线索；②商详/字幕/视觉研究与交接；③至少3条发布原片、覆盖2账号的关键视听内容研究；④我方上线效果。完成②不能自动签③④。当前两平台原片与视觉研究、限定短语自动核验通过；抖音发布作品到目标商品ID和冲突关键话术仍待。抖音不以变体SKU为硬门槛；不强制所有样本完成人工全片逐字听审，也不把无后台经营效果等同于已有研究无效。

Social Account Doctor固定版本已静态审阅，整包未安装。GPU部署与已有素材语义复验已经完成；后续仅针对抖音发布作品目标商品ID及仍改变结论的词句补证，变体细节只在另有明确任务时继续。已确认的结构可先交编导研究，不以扩大泛搜索代替缺失字段，不让局部疑词阻断其余有证据的交接。
