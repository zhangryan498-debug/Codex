# 竞品交接：当前提案状态与事实用途

仅在竞品研究以结构化状态交接一个明确的当前比较或使用提案时适用。它明确机器状态的对象，不替代原岗位规则、证据判断、价审或经营授权；其他独立研究条目可另立提案评估，不因某个比较失败而一律否定所有事实。

`disposition`、各路 `handoff.status` 与接收岗 `own_review_state` 均指该当前提案。可保留的历史、分站或未形成结论的事实，单独写入 `allowed_claims`／`allowed_use`，不得以这些局部用途放宽主状态。

| 当前提案 | 各路交接的最低限制 | 接收岗处理 |
|---|---|---|
| `BLOCK_COMPARISON` | `BLOCKED` | 保持阻断；可列有出处的历史／分站事实及禁止推论，明确整改或补证后另审 |
| `PENDING_EVIDENCE` | `PENDING` | 不得改为 `RESEARCH_ONLY`；发现新的确定失败可升级为 `BLOCKED` |
| `PASS_RESEARCH` | `RESEARCH_ONLY` | 在所述合成／研究范围内接收；有本岗必要证据缺失或确定失败可收紧，不因真实经营授权尚缺而否定原本成立的限定研究 |

接收主状态不得比上游当前提案或本路交接更宽松。若发现上游提案误判，将反证和补证请求交回上游复核，保留本次状态；不能在原快照上静默解除。修订后的提案须另留版本、输入与回执。

例如，当前优惠不成立时，旧报价仍可作为带日期的历史事实保留，但当前优惠比较的主状态保持阻断；不同站点或币种的事实可分别记录，但不能借“仅作素材研究”让未经支持的跨币种比较进入可用状态。未知也不等于零。

每个主提案和每路交接都给出明确下一步句子：补何种证据、复核什么、送哪个离线环节或暂缓哪项提案。状态词本身不算动作。正文、主状态与局部允许用途须一致。

限定研究可用不代表素材复制权、我方实物卖点、真实来源认证、价格或预算授权。成本、费率、券分摊、底价、权益或经营权限未知时，不生成可执行价格、宣称或投放放行；所有本轮离线结果仍为 `not_authorized`。
