# TikTok 东南亚直播运营方法论

本 Skill 面向 TikTok 东南亚直播场次操盘。

⚠️ **不可套用抖音规则**：抖音的店播 52% 主力地位、仅退款、大盘 433 结构在东南亚不成立。东南亚直播渗透率低、COD 占比高。

---

## 1. 岗位定义与考核指标

### 岗位定位
TikTok 出海业务的**直播结果承接方**，核心能力是**人货场匹配 + 本地化 + 履约风控**的三合一。

与抖音直播运营的层级对应关系相同（专员/中控 → 直播运营 → 主管 → 负责人），但东南亚版本额外要求跨文化沟通、本地语言能力、跨境履约链路理解。

### 考核指标

下表「JD 频次」列统计自 `research/jd/tiktok-live-ops.md` 的 **79 篇正文型 JD**（按正文出现频次，非搜索摘要）；「东南亚特有」列来自 `docs/knowledge/platform-model.md` 的平台事实。**两张表要一起看**——JD 告诉你市场考核什么，平台模型告诉你这些指标在东南亚会被 COD 扭曲成什么样。

| 指标 | JD 频次 | 说明 | 东南亚特有 |
|---|---|---|---|
| **互动 / 评论** | **29/79 (37%)** | 直播相对短视频最独特的即时指标 | |
| **转化率 / 成交** | 23/79 (29%) | 成交密度 | 转化率须按签收口径折算 |
| **并发观看 / 观看人数** | 18/79 (22%) | 峰值在线、reach | |
| **签收 GMV** | 14/79 (17%) | 订单 GMV × 实际签收率 | **不可直接用订单 GMV 汇报** |
| **达人 / KOL 产出 ROI** | 13/79 (16%) | 达人合作带来的 GMV 占比与佣金效率 | 直播渗透率低，主要靠联盟导流 |
| **净 ROI** | 8/79 (10%) | 扣退货/拒收后 | 退货不退佣金与平台费 |
| **签收率 / 拒收率** | — | 生命线指标 | 触阈值直接限流 |

**考核形态的关键事实（JD 原文归纳）**：直播运营几乎**不被考核过程指标**（发布量、场次准备度），而是**直接背 GMV 与转化**。平台方岗位（如 TikTok 官方 Business Development Manager）考核的则是**生态渗透率**——推动商家使用 Shop 与内容工具，而非个人销售额。

**与抖音直播岗的考核重心差异（不可互换）**：
- 抖音侧（26 篇 JD）：**GMV 由 15/26 篇直接负责**，是绝对第一考核项；ROI/转化率各 9/26。
- TikTok 东南亚侧（79 篇 JD）：**互动/评论 37% 排在第一，GMV 只有 17% 排到第四**。原因有二——① 直播渗透率低，直播的自然流量要靠互动与联盟内容导流才能起量，互动是流量能否扩散的**先行指标**；② COD 环境下 GMV 本身被退货扭曲，不如互动率与转化率稳定可归因。
- **实操含义**：东南亚直播场次中，**互动率（评论/点赞/观看）必须作为一级过程指标实时盯**，不能等场后复盘才看；互动掉了而 GMV 还没掉，说明起量已经停了。抖音侧不存在这个提前量。

### 硬性任职门槛
- **学历**：本科及以上（海外岗通常高于国内）
- **年限**：直播运营 2 年以上为主流门槛；主管 3-5 年；负责人 5 年以上 + 团队管理
- **业绩门槛**：可追溯的场次 GMV 业绩（**东南亚口径建议注明是签收 GMV 还是订单 GMV**）、0→1 起盘经验
- **语言**：英语硬要求；**目标站点本地语言几乎必需**（主播话术、客服沟通都靠它）
- **工具**：TikTok Shop 后台、Affiliate/联盟后台、LIVE 直播伴侣、TikTok Ads Manager、Excel/数据透视表
- **本地资源**：本地仓配资源、本地客服、本地达人网络
- **软性**：跨文化沟通、抗压与直播节奏、快速应变与临场反应（断播、超卖、拒收率飙升）

## 2. COD 预期管理话术规范（本岗位的第一专业动作）

### 2.1 为什么这是止损不是技巧

印尼 COD 订单占约 68%，COD 订单退货率 35%–45%。**退货只退买家全款，达人佣金和平台费不退回。** 一次高拒收率的直播，账面上有 GMV，实际是净亏。

### 2.2 五项必答异议

| # | 异议 | 直播话术要点 |
|---|---|---|
| 1 | **仅支持 COD/货到付款** | 明确说明只支持货到付款，让买家在**下单前**知道 |
| 2 | **拒收可能性坦诚说明** | 说明拒收会影响后续购买权限 → 反而降低拒收率 |
| 3 | **本地退货政策与联系方式** | TikTok 本地客服渠道，非国内话术 |
| 4 | **尺码对照** | 真人上身 + 尺寸表，直播间挂图/口播都要有 |
| 5 | **本地发货时效** | 3–7 天，与实际一致 |

### 2.3 话术设计原则
- **不回避、不美化**：观众对"只支持 COD"的接受度取决于是否被提前告知
- **说清楚后果**：拒收会影响后续购买权限
- **配套视觉**：尺码对照图、尺寸表在直播间常驻
- **给替代方案**：预付优惠（预付退货率 12% vs COD 35-45%），如平台允许可引导

### 2.4 效果验证
直播复盘必须记录：签收率、拒收率、拒收原因分布（尺码/色差/预期落差/物流时效/无购买意向）。**拒收原因分布是下一次直播改进的唯一可靠依据。**

## 3. 排品方法（东南亚版）

用 `templates/直播运营/直播排品表.md`。五种角色同抖音，但**选品标准不同**：

| 角色 | 东南亚特别要求 |
|---|---|
| 引流款 | 低客单（印尼 $5–15）、规格通用、无需尺码选择 |
| 利润款 | **避开高退货类目**（服饰、美妆需格外谨慎），佣金成本率可控 |
| 爆款 | 已验证本地达人可讲、拒收率已知的商品 |
| 形象款 | 高客单、需本地认证资质 |
| 清尾款 | 库存周转优先，赔本清退也要算清 |

### 3.1 COD 备货口径
**按下单量备货，不是按签收量。** 拒收率 35–45%，按签收量备必然断货。断货影响推荐权重。

### 3.2 时效与承诺
本地仓 3–7 天，超时自动判罚赔付订单金额 10%。**直播话术里的时效承诺必须与实际一致。**

## 4. 联盟内容导流协同（东南亚直播的主要流量来源）

### 4.1 为什么必须做
东南亚直播渗透率低于国内，短视频带货是主战场。**只守着自己直播间等流量是错的。**

### 4.2 双向导流
```
联盟达人短视频内容 → 引导进直播间（TikTok 内容种草 → 直播成交）
     ↑                                ↓
     └──── 直播切片做联盟内容 ←────┘
              （Spark Ads 放大，需达人授权）
```

### 4.3 排期协同
- 直播排期需与联盟达人短视频排期对齐（达人内容是直播的流量来源）
- 直播切片需及时剪出用于联盟投放（Spark Ads）
- **寄样 → 样品审核 3–5 天 → 合作后 72 小时内排直播**

### 4.4 本地节庆
斋月/开斋节等提前 6–8 周启动整条链路。

## 5. 履约风控贯穿场次

### 5.1 平台红线（每场前核对）

| 指标 | 阈值 | 后果 |
|---|---|---|
| 拒收率 | 连续 7 天 >45% | 限制商品曝光 |
| 拒收率 | 单日 >30% 持续 2 天 | 自动暂停推流 72 小时 |
| 签收率 | 连续两周 <60% | 限制短视频挂车功能 |
| 发货仓 | 非本地认证仓 | 虚假发货，3 倍罚款最高 $500 |
| 虚假发货 | 连续 3 单 | 冻结账户，已结佣不退 |
| 物流状态 | 48 小时无更新 | 判定虚假发货，扣分至停权 |
| 时效 | 超 3–7 天 | 自动判罚赔付订单金额 10% |

### 5.2 场前必查
□ 本地认证仓发货能力　□ 备货量（下单量口径，≥15 天销量）　□ 当前签收率与拒收率　□ 现金流覆盖（≥3 个月）　□ 类目认证　□ 商品评分 ≥4.3 且近 30 天售出 ≥50 件（达人可见门槛）　□ COD 五项异议话术已就位

### 5.3 场中监控
拒收率实时监控；**触阈值立即降预算、暂停推流**，保护账号权重（挂车能力一旦受限，整个内容链路失效）。

## 6. 场次复盘规范（按站点）

用 `templates/直播运营/直播复盘表.md`。**场后 24 小时内完成。**

### 6.1 常规指标
场观、在线、停留、互动率、点击率、转化率、订单、GMV、投流消耗、表面 ROI、**净 ROI**、净利。

### 6.2 东南亚必加指标
| 指标 | 说明 |
|---|---|
| **COD 订单占比** | 结构指标 |
| **签收率** | 生命线 |
| **拒收率** | 生命线 + 限流风险 |
| **本地仓发货及时率** | 时效风险 |
| **本场预估回款时间** | COD 签收后 15 天 |
| **拒收原因分布** | 尺码/色差/预期落差/物流时效/无意向 |

### 6.3 逐款问题标注
讲解不清（本地化表达问题单列）/ 卖点弱 / 价格无优势 / 库存不足 / 素材缺失 / 流量不足 / 评论区质疑未处理 / **COD 疑虑未处理** / 履约疑虑。

## 7. 常见错误与雷区

| 错误 | 后果 | 正确做法 |
|---|---|---|
| **话术不讲 COD** | 拒收率飙升，直接亏损 | 五项异议逐条讲 |
| **不讲拒收后果** | 买家不知情 → 拒收 | 坦诚说明 |
| **直译话术** | 异国市场无效 | 本地达人协助校对 + 彩排 |
| **按签收量备货** | 必然断货，影响推荐权重 | 按下单量备 |
| **不看签收率就放量** | 触发限流、限挂车 | 场前必查阈值 |
| **只看订单 GMV** | 掩盖真实经营状况 | 用签收 GMV 与净 ROI |
| **跨站合并复盘** | 掩盖站点差异 | 按站点分列 |
| **不信本地达人、不做本地化** | 转化起不来 | 本地团队深度协作 |
| **只守直播间不导流** | 曝光不足 | 与联盟短视频双向导流 |
| **时效承诺超实际** | 超时赔付 10% | 与 3-7 天一致 |
| **虚假憋单/逼单** | 违规 | 稀缺机制真实 |
| **不做本地化话术库** | 每场从零开始 | 分站点分语言沉淀 |
| **佣金超 25% 不核算** | 低客单下必亏 | 建联前先算利润线 |
| **不经测试直接本地店** | 大额保证金占用 | 马来审核快适合先小规模测品 |

## 8. 平台差异提示（东南亚专属，不可外传）

| 东南亚特有 | 说明 |
|---|---|
| **COD 占比约 68%（印尼）** | 退货 35-45%，预付 12% |

## 9. 数据与规则的时效性规范

- **费率、佣金、平台规则、阈值**：变动频繁，标注来源与时点，注明需复核。
- **退货率、拒收率、签收率**：行业实操区间，标注为区间参考值。
- **站点数据不可跨站套用**：任何结论必须限定站点。
- **数据通道权威源**是项目 `docs/knowledge/data-channel.md`；取数走项目 `data-pipeline/` 下的采集器。**抖音侧零凭据通道已完全跑通**：热榜（`douyin_public.py`）+ 推荐流/话题真实体量/创作者画像/作品详情/评论（`douyin_feed.py`，推荐流自举，不需要种子 ID、不需要登录、不需要分享链接）。TikTok 侧采集器代码就绪，需 API token。外部数据只用于趋势与竞品判断，**经营口径（结算/真实退货/实收）必须来自店铺后台**。
- **取数三条纪律**：① L0 热榜的 `video_count` / `discuss_video_count` **不是话题体量**，不可当量级证据，只能用于词条间相对热度排序；② 话题真实体量看 `challenge/detail` 的 `view_count` / `user_count`；③ 抖音搜索端点需登录，**「热榜词 → 话题 cid」目前无免登录通道**，垂类批量采样需托管 API 或用户给一条分享链接作种子。
- **平台知识库权威源**是项目 `docs/knowledge/platform-model.md`；与最新公告冲突以公告为准并立即更新。
- **不确定判断标注置信度**，说明需要谁去验证。
