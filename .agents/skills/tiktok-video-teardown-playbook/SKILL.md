# TikTok 优质短视频拆解分析专员方法论

本 Skill 面向 TikTok 东南亚（印尼/泰国/越南/马来/菲律宾）爆款拆解场景。

⚠️ **不可套用抖音规则**：抖音的中小达人下沉、搜索承接分析、店播拆解价值等结论在东南亚不成立（东南亚头部不集中、货架心智未建立、直播渗透率低）。

---

## 1. 岗位定义与考核指标

### 岗位定位
TikTok 出海内容链路的**逆向工程角色**，处于「本地爆款内容池 → 结构化拆解 → 本地化可行性评估 → 方法论沉淀 → 反哺本地生产」这条反馈回路的入口端。

### 与抖音拆解分析专员的三大差别

| | 抖音拆解 | TikTok 拆解 |
|---|---|---|
| 追踪对象 | **下沉到中小达人**（头部仅贡献 9%） | **盯达人群体套路**（头部不集中，长尾化） |
| 拆解产出 | 结构 + 可复用结论 | **结构 + 本地化改造难度 + 所需本地物料** |
| 转化链路 | 搜索/商品卡/支付 | **含 COD 拒收风险与拒付话术** |

### 考核指标

| 指标 | 说明 |
|---|---|
| **本地化要素库沉淀量与有效性** | 结构化可复用的要素数，以及被本地验证跑出爆款的次数 |
| **本地化改造难度评估准确率** | 标注"直接可用"的要素实际在本地跑出的比例 |
| 选题库/脚本模板输出（分站点） | 本地化素材生产效率 |
| 周/月度复盘报告 | 含数据、洞察、迭代建议与落地跟踪 |
| 达人群体覆盖率 | 追踪的本地达人群体数量 |
| 本地趋势与节庆内容研究 | 是否抓住本地节点 |

### 硬性任职门槛
- **学历**：本科及以上偏主流
- **经验**：1–3 年为主；有出海/TikTok 内容分析经验者优先
- **语言**：英语硬要求；印尼语/越南语/泰语/马来语为强加分（**做本地化评估，这项几乎是决定性的**）
- **工具**：Excel、SQL、数据抓取工具；熟悉 TikTok 数据看板与第三方工具
- **跨文化理解**：能判断一个梗、一种场景、一个情绪在当地是否成立

## 2. 本地化改造难度四档评估（核心方法论）

每个拆解出的爆点都必须落到四档之一：

| 档位 | 定义 | 典型例子 | 处理方式 |
|---|---|---|---|
| **直接可用** | 机制与文化无关，跨市场通用 | 价格对比冲击、产品前后对比、倒计时促单 | 可直接进脚本 |
| **需换语言** | 机制成立，但语言必须母语者重写（直译无效） | 痛点场景口播、方言梗、谐音文案 | 找本地达人/母语者重写 |
| **需换文化符号** | 梗、手势、场景、食物、节日必须本地化替换 | 特定手势、货币梗、本地节庆玩法 | 换符号并重新验证情绪强度 |
| **结构可用需重拍** | 叙事骨架可复用，但素材必须重新拍摄 | 特定场景剧情、达人出镜类内容 | 用本地达人/本地场景重拍 |

### 评估的三个层次（不能只做第一层）

```
第一层：语言能不能通？          ← 最低要求
第二层：用户心理前提在本地成立吗？  ← 关键
第三层：改完还剩多少效力？         ← 最高要求
```

**只做第一层就下结论，是本岗位在东南亚最常见的失职。**

第二层的追问：
- 这个爆点依赖的社会文化前提在当地存在吗？（例：某些"懒人神器"叙事依赖特定生活方式的拥挤度）
- 目标人群的消费习惯匹配吗？（印尼 $5–15 客单 vs 泰国 $10–30，对同一爆点的耐受度不同）
- 情绪触发点当地是否同源？（例：家庭观念、宗教情感、节庆场景）

第三层的追问：
- 换语言后"梗感"还剩多少？
- 换成当地场景后，代入感是增强还是削弱？
- 改造后是否引入新的合规风险？

### 输出格式
每个爆点在拆解报告中标注：
```
本地化改造难度：□直接可用 □需换语言 □需换文化符号 □结构可用需重拍
用户心理前提：<在目标站点是否成立，为什么>
改造后效力预估：<高/中/低，理由>
所需本地物料：<本地达人/本地场景/样品/本地货币与单位>
```

## 3. 达人群体追踪策略

### 3.1 为什么盯群体而非单账号
东南亚头部不集中，本地网红长尾化。**一个账号可能是偶然，群体规律才是打法。**

### 3.2 追踪表设计（`templates/拆解分析/对标账号追踪表.md`）

必须标注：
| 字段 | 作用 |
|---|---|
| 达人属性 | **本土 / 跨境**（带量能力差异巨大） |
| 层级 | 头部（>50 万粉）/ 中腰（5–50 万）/ 尾部（1–5 万） |
| 佣金带 | 头部 20-25% / 中腰 12-18% / 尾部 10-15%（**从其合作成本反推利润空间**） |
| 站点 | 印尼/泰国/越南/马来/菲律宾 |
| 内容形式与结构 | 群体共性 |
| 节庆属性 | 是否节庆专属 |

### 3.3 群体追踪表（独立于单账号表）
记录：账号群数量、共同特征、共同套路、平台、站点、更新日期。

### 3.4 爆款判定口径
同一账号内对比中位数，**口径一经确定不得中途更改**。

## 4. COD 履约兼容性检查（必查项）

某些内容形式在 COD 场景下天然退货率高。拆解时必须逐条检查：

| 内容特征 | COD 风险 | 判定 |
|---|---|---|
| 服饰展示但未展示尺寸 | 高（尺码不合退货） | ⚠️ 标注"抄则退货高" |
| 化妆品过度承诺效果 | 高（预期落差） | ⚠️ 标注合规 + 退货双风险 |
| 大件/易碎品特写展示 | 中高（二次销售困难） | ⚠️ 慎入 |
| 未说明"仅支持 COD"的内容 | 中（买家不知情→拒收） | ⚠️ 需补话术 |
| 通用规格商品展示 | 低 | ✅ 可放心用 |

**输出要求**：每条可复用结论必须标注"在 COD 场景下的履约兼容性"。

## 5. 转化链路还原（含 COD 阻力）

```
流量来源（推荐流 / 搜索 / 达人主页）
  ↓
点击承接（商品页 / 达人主页挂车）
  ↓
支付路径（COD / 本地钱包）
  ↓
★ 阻力点：拒收风险、拒付话术是否处理、是否明示 COD
```

TikTok 侧还要额外看：
- 商品评分是否 ≥4.3（低分商品内容再爆也难带量）
- 规格通用度展示
- 认证展示是否影响信任

## 6. 本地节庆拆解

**斋月/开斋节/泼水节/双九/双十/圣诞** 是东南亚的内容与消费节点。

拆解节庆内容时必须标注：
- **节庆属性**：该爆点是否只在特定节庆成立
- **跨节庆可迁移性**：去掉节庆符号后，机制还剩多少
- **提前量**：该类内容需要提前 6–8 周启动（达人排期 + 样品 + 本地化物料）

**"节庆有效但不可迁移"的结论，必须显式写出来**——否则会被当成全年可用打法，浪费资源。

## 7. 要素库六要素规范

用 `templates/拆解分析/爆点要素库.md`。每条要素六项齐全：

| 要素 | 说明 |
|---|---|
| 具体内容 | 到底怎么做的（禁止空词） |
| 底层机制 | 为什么会有效 |
| 适用商品/类目 | |
| **适用站点** | 印尼/泰国/越南/马来/菲律宾 |
| 可复制度 | 高/中/低 |
| **本地化改造难度** | 四档之一 |

### 禁止空词
"多巴胺""情绪拉满""强冲突""真实感"这类词**不是要素**。判断标准：另一个人看完能不能照着拍出来？不能，就是空词。

### 淘汰规则
- 同一要素**连续 5 次应用未跑出高于账号中位数的作品** → 降级
- **连续 3 个月无任何验证记录** → 移入归档区

## 8. 常见错误与雷区

| 错误 | 后果 | 正确做法 |
|---|---|---|
| **不评估本地化难度** | 抄过来在当地失效 | 四档评估 + 效力预估 |
| **只做语言层不评估心理前提** | 翻译通但打不动 | 过第二层、第三层 |
| **跨站点套用爆点** | 印尼有效泰国无效 | 标注适用站点 |
| **盯单账号不盯群体** | 结论不代表市场 | 建群体追踪表 |
| **忽略本土 vs 跨境达人差异** | 错判带量能力 | 追踪表标注达人属性 |
| **不查 COD 履约兼容性** | 抄来的内容引发高退货 | 必查项 |
| **把节庆爆点当全年打法** | 资源浪费 | 标注节庆属性与可迁移性 |
| **描述代替归因** | 拆解无价值 | 每条结论回答"为什么" |
| **要素写成空词** | 要素库无法使用 | 六要素齐全 |
| **只看内容不看转化链路** | 漏掉 COD 阻力 | 还原完整链路 |
| **不落回生产** | 拆解与生产两张皮 | 回灌编导/美工/选品/投手 |
| **拿第三方估算当实数** | 对比失真 | 标注估算口径 |

| 东南亚特有 | 说明 |

## 10. 数据与规则的时效性规范

- **本地趋势、流行 BGM/hashtag**：时效性极强，**发布前必须重新确认**。
- **竞品数据**：标注站点与采集时间。
- **第三方工具数据**：标注为估算，说明所用工具。
- **数据通道权威源**是项目 `docs/knowledge/data-channel.md`；取数走项目 `data-pipeline/` 下的采集器。**抖音侧零凭据通道已完全跑通**：热榜（`douyin_public.py`）+ 推荐流/话题真实体量/创作者画像/作品详情/评论（`douyin_feed.py`，推荐流自举，不需要种子 ID、不需要登录、不需要分享链接）。TikTok 侧采集器代码就绪，需 API token。外部数据只用于趋势与竞品判断，**经营口径（结算/真实退货/实收）必须来自店铺后台**。
- **取数三条纪律**：① L0 热榜的 `video_count` / `discuss_video_count` **不是话题体量**，不可当量级证据，只能用于词条间相对热度排序；② 话题真实体量看 `challenge/detail` 的 `view_count` / `user_count`；③ 抖音搜索端点需登录，**「热榜词 → 话题 cid」目前无免登录通道**，垂类批量采样需托管 API 或用户给一条分享链接作种子。
- **平台知识库权威源**是项目 `docs/knowledge/platform-model.md`；与最新公告冲突以公告为准并立即更新。
- **不确定判断标注置信度**，说明需要谁去验证。
- **抓取与使用数据注意平台规则与数据合规边界。**
