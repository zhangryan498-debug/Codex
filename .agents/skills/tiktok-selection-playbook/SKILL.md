# TikTok 东南亚选品运营方法论

本 Skill 面向 TikTok 东南亚出海选品与货盘运营。

⚠️ **不可套用抖音规则**：抖音的投流税、仅退款、商品信息质量分、阶梯升佣在东南亚不成立；东南亚的 COD 退货、跨境物流、类目认证、站级费率在抖音不存在。

---

## 1. 岗位定义与核心认知

### 岗位定位
TikTok 出海业务的**商品利润责任人**。核心产出是：能通过本地达人讲清楚、能扛住 COD 退货、能合规上架、能跨物流的货盘。

### 核心认知（这个岗位存在的理由）

**在东南亚，"选对品"和"选到能赚钱的品"是两件事。**

```
抖音选品：选得对 → 内容能爆 + 千川能投 → 赚钱
东南亚选品：选得对 → 本地达人能讲 + COD 扛得住 + 物流能走 + 认证能过 → 才谈得上赚钱
```

最常见的失败不是"没选到爆品"，而是**选到爆品但退回来还亏钱**。因为 COD 退货只退买家全款，**达人佣金和平台费已经付出去了**。

### 考核指标

下表频次统计自 `research/jd/tiktok-selection.md` 的 **12 篇正文型 JD**（按正文出现频次）；「本岗位口径」列说明本 Agent 的算法与 JD 考核语义的对应关系。

| 指标 | JD 频次 | JD 原文 | 本岗位口径 |
|---|---|---|---|
| **GMV / 行业 GMV** | 10/12 | 「并对行业 GMV 增长负责」（字节·越南 FMCG）；「保障店铺 GMV、转化率等核心指标达成」 | 落在**签收 GMV**，不是订单 GMV |
| **毛利率 / 量本利 / 利润** | 8/12 | 「量本利分析」；「对最终的实收和毛利负责」；「对渠道 GMV、利润率……负责」 | 落在**真实单均净利**（扣退货/拒收/佣金不退还），比毛利率更严 |
| **爆品命中率 / 单品打爆成功率** | 5/12 | 「有成熟的选品思路和方法论……有**多次成功推出爆款**的经历」；「打造可复制的爆品模型」 | 测品成功阈值 + 爆品模型沉淀 |
| **SKU 动销率 / 库存周转 / 售罄率** | 5/12 | 「保持库存动销的良好周转」「采购备货预测」「避免缺货和滞销」 | **按下单量备货**（非签收量），断货影响推荐权重 |
| **价格力** | 2/12 | 字节官方：「负责价格力、品类扶持等专项在大促的策略拆解、定标和落地支持」 |
| **品类渗透率 / 供给宽度深度** | 4/12 | 「扩大商家和商品生态的宽度与深度，高效挖掘优质供给」 | 品类级供给规划视角 |
| **大促招选渗透率 / 让利深度 / 供给稳定性** | 2/12 | 字节官方大促选品专属指标 | 与活动运营协同 |
| **选品决策准确率** | 样本未明文 | 由「参与核心商品决策，保障选品的质量」隐含承担 | 决策漏斗后验，用爆品命中率反推 |

**与抖音选品岗考核结构的差异（不可互换）**：抖音侧的"利润率"是**账面毛利**，其失真源是**仅退款**（货损+佣金不退）；TikTok 侧的"量本利"失真源是 **COD 退货 35–45% + 退货不退佣金与平台费 + 回款 12–18 天**。因此同一套「毛利率」在两地**不可直接横向比较**，跨平台比选品必须先各自还原到真实单均净利。

## 2. 分站选品六维评估（列组 B）

用 `templates/选品运营/选品评估表.md`。

| 维度 | 关键问题 | 红线参考 |
|---|---|---|
| **跨境物流属性** | ≤500g 优；液体/易碎/大件/含电池/超重减分 | COD 退货预估 >45%（触限流阈值） |
| **达人可讲性** | 是否好讲、有无演示性/冲突感 | 达人一句话讲不清 → 排除 |
| **类目认证门槛** | 认证周期与成本 | 认证周期 >60 天且无备选 → 降级 |
| **COD 退货预估** | 服饰/美妆通常 20%+，标品小件更优 | 预估 >45% → 排除 |
| **本地化改造成本** | 语言/文化门槛 | 需重拍且成本高于利润 → 排除 |
| **目标站费率适配** | 印尼/泰国/越南佣金+达人佣金上限 | 佣金 >25% 且低客单 → 排除 |

### 2.1 COD 退货预估方法
按五个维度预估，**取保守值**：
1. **品类基准**：服饰 > 化妆品 > 3C 配件 > 家居日用 > 标品小件（⚠️ 行业参考区间，需用自有历史数据校准）
2. **规格复杂度**：有尺码 > 有色号 > 有套装组合 > 无规格
3. **价格敏感度**：客单价越低、冲动购买越多，退货越高
4. **预期落差**：详情页承诺越夸张，退货越高
5. **预付 vs COD**：COD 单退货率显著更高（印尼 COD 35-45% vs 预付 12%）

**预估方法要固化并每季度用实际数据校准。** 这是本岗位最需要沉淀的方法论资产。

### 2.2 达人可讲性判断
问四个问题：
1. **15 秒内能说清卖点吗？**（一句话卖点）
2. **有可视化演示点吗？**（能对比、能实测、能变形）
3. **本地用户有相关生活场景吗？**（场景是否存在于当地）
4. **达人能不能拿到样品并真讲？**（是否需特殊道具/场地）

## 4. 测品方法

用 `templates/选品运营/测品计划表.md`。

### 4.1 东南亚四类测品
| 类型 | 看什么 |
|---|---|
| 短视频矩阵测款 | 本地化内容能否起量 |
| **联盟达人测款** | **本地达人能否带量（东南亚最关键）** |
| Ads 测款 | 素材可投性 |
| 直播测款 | 直播承接能力 |

### 4.2 测品成功标准必须按签收率折算
**测出订单不等于测出利润。** 成功阈值要写成"签收 GMV"或"净 ROI"，不能写订单数。

### 4.3 控量与合规
- **单量测试控量**，避免被判定异常刷量
- **不通过虚假优惠/虚假折扣冲量**
- **不诱导好评**（TikTok 罚款 $50 起）

### 4.4 站点节奏差异
**印尼**：最大市场但 COD 占比最高、退货最高、审核 14–20 天 → 需更谨慎的品控与更长排期
**马来**：审核 7–10 天 → **适合新卖家首阶段小规模测品**
**选品顺序应按站点策略排**，不是同一个品在所有站同时上。

## 5. 认证与合规前置排期

| 项 | 要求 |
|---|---|
| 类目认证 | 化妆品/食品/电器必须前置完成，认证周期进排期 |
| 印尼 API-UD | 进口商登记方可清关 |
| 本土店保证金 | 约 2000 万印尼卢比（≈$1300） |
| 中国主体直连 | **无法使用 COD** |
| 寄样与审核 | 寄样 → 样品审核 3–5 天 → 合作后 72 小时内排直播 |

**认证没完成 → 不能上架 → 不能测品 → 达人拿不到样品 → 不能带货。** 这条链上任一环延迟，整条链路都停。所以认证周期必须进排期表并设提醒。

## 6. 库存与现金流结构

### 6.1 备货
- **按下单量备货，不是按签收量**（拒收 35–45%）
- **≥15 天销量预估**（断货影响推荐权重）
- 直播专属备货与分货机制（与仓储对接）

### 6.2 现金流
- COD 回款 12–18 天（签收后 15 天）
- **现金流覆盖 ≥3 个月运营成本**
- **高退货 + 高账期的品必须降权重**——退货占用的现金 + 佣金已付出 + 二次销售困难，是三重损耗

## 7. 常见错误与雷区

| 错误 | 后果 | 正确做法 |
|---|---|---|
| **不估 COD 退货就选品** | 表面盈利实则亏损 | 退货预估为准入项 |
| **把订单 GMV 当利润** | 严重高估 | 乘实际签收率 |
| **跨站套用费率** | 印尼站佣金设崩 | 按站按当前值核算 |
| **引用旧费率** | 2026 已多次上调 | 标注时点并注明需复核 |
| **选重货/液体/易碎** | 物流吃掉利润 | ≤500g 优先 |
| **忽略达人可讲性** | 选出来带不动 | 四问法判断，出可讲性卡片 |
| **认证没完成就排测品** | 整条链路停摆 | 认证周期进排期 |
| **按签收量备货** | 必然断货 | 按下单量 + 15 天预估 |
| **不评估现金流** | 回款断裂 | 覆盖 ≥3 个月 |
| **同一品全站同时上** | 忽略站点差异 | 按站点策略排布 |
| **测品成功标准用订单数** | 测出假爆款 | 按签收 GMV / 净 ROI |
| **不控制测试单量** | 判定异常刷量 | 控量测试 |
| **不输出分站复盘** | 无法沉淀站点方法论 | 分站周月季报 |
| **直接搬抖音选品逻辑** | 跨境成本与退货完全没算 | 按平台分别测算 |

## 9. 数据与规则的时效性规范

- **费率与佣金**：东南亚站点 2026 年已多次上调，**每次输出必须标注来源与时点并注明需复核**。
- **退货率/拒收率/签收率**：行业实操区间，标注为区间参考值；**每季度用自有数据校准**。
- **站点数据不可跨站套用**：任何结论必须限定站点。
