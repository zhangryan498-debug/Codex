# 选品证据与硬门禁

先读项目 `docs/双平台选品数据使用规范.md`。涉及货源、供应商或联系方式时再读 `docs/选品供应商搜集与筛选规范.md`。项目资源不可用时，记录缺口，仍可比较任务输入中已有证据；不为补齐报告擅自采集、外联、付费或下单。

## 证据矩阵

按平台/站点/商品ID/SKU分别保留以下维度；每项写来源、观察起止日、抓取日、样本边界及适用范围：

| 维度 | 最少辨明的证据与限制 |
|---|---|
| 需求 | 商品销量或搜索/内容趋势是什么口径；节点性、连续性与窗口可比性；热度和第三方销量估算不能冒充本店成交或预测 |
| 竞争 | 同SKU/近似款/类目样本的区别、价格单位与促销口径、样本覆盖；合作达人不等于同行卖家，首屏不等于全市场 |
| 退货 | 退款、仅退款、退货、拒收和COD各自分母与费用返还规则；本店观察、行业参考、给定情景分列，不能跨站拼平均 |
| 物流 | 尺寸克重、包装、易碎/液体/电池属性、发货地/目的地、计费单位、到仓与可售时间；属性风险不自动等于禁售 |
| 供应链 | SKU匹配等级、真实经营主体、MOQ/包装倍数、报价期、供货周期、在库/预售声明及履约待核项 |
| 利润 | 成本和收入的单位、税费/佣金/退款返还与广告口径、币种、价格证据、成本完整性；无采购成本不报真实利润 |

抖音另核内容演示与广告承接、预期差、质量/材质和售后证据。TikTok另核当地场景与达人可讲性、语言、本地化/认证排期及COD履约；不把抖音机制移作TikTok规则，也不把站点历史参数当当前值。

## 硬门禁与评分

- 为法规/类目资质、供应商匹配与履约、利润、关键证据有效性分别保留状态及依据。确证失败时停止推荐其进入实际测品/采购；关键证据缺失、过期或冲突时标“待核”，仍可交付其他维度分析及明确条件下的规划。规划可计算不等于商品准入通过。
- 费率、平台门槛和法律适用须按站点、主体、类目、履约与日期核实；没有当前依据时交给责任岗补核。本 Skill 不内置行业硬阈值；原模板/JD数值只作历史方法来源。
- 若用户要求打分，先列模型来源/版本、权重、转换函数、阈值、适用范围及批准状态。未批准的模型只能作标明的敏感性情景；不称公司标准。权重归一且原始数可回溯。缺关键维度不填0、均值或伪造默认值，也不重新分摊权重凑完整排名；最多给证据支持的相对比较。
- 分数、ROI或销量不能抵消任一硬门禁失败或待核。跨SKU/币种/站点的ROI不得简单平均放行；需要汇总时先明确可加总的分子与分母、同口径和币种，结果仍不代表执行授权。
- 关键词命中仅提示审查上下文、具体声称、适用规范及举证；不以某词出现即断定违法。对外声称、资质和发布审核交原责任岗。

## 数据与供应商复用

Just One `sale_axis`与`month_sale`独立，不混成同一序列；`cooper_author_num`不是同行卖家数。FastMoss 7/28/90天汇总与日序列分别保留实际日期，疑似延迟的最新0不用于断言下滑。原始响应空白也不等于无需求。`Rp22.938`展示可按印尼格式解释为22938 IDR；JSON number `22.94`不擅自乘1000。价格冲突先挂起依赖它的利润结论。

供应商沿用三级：A“确证同SKU”须货号/包装标签/样品等硬证据且关键规格无冲突；B“可询价近似款”有具体商品与同一商家的公开商务入口，并列待核差异；C“仅线索”不能作已确认供货。外形相似不证明同工厂或原爆品货源，竞店不默认厂家。复用既有商品页、联系人来源与查证日期，同主体去重；公开标价不冒充实时报价。记录币种、计价单位、变体、MOQ、包装、预售、发货地和补货周期。缺单位或未核运税与履约路径时不比较到仓成本。

## 原成果衔接

原模板按任务复用：`templates/选品运营/选品评估表.md`、`商品利润测算表.md`、`测品计划表.md`。不复制模板，也不自动采用其中旧费率/阈值/简化公式。利润需按明确收入与费用基数重算，退货和费用返还不重复扣算；不把“单件净利再乘签收率”等旧表简式当普遍恒等式。定价、保本价和不破价结论转原商城/活动价格门禁，不使用上游保本价四舍五入结果放行。

测品草案保留观察窗口、成功/失败标准、最小样本、预算止损与库存依赖；阈值由任务或获准方案给出。未实际测品不报告经营效果。资料完整的合成方案可标“情景内算清，待审”；公开市场研究可形成候选与补证优先级，不因缺店铺后台数据一律停止，也不声称真实盈利。
