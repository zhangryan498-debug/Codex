# TikTok 前端美工设计师方法论

本 Skill 面向 TikTok 东南亚电商视觉场景。

⚠️ **不可套用抖音规则**：抖音的"单图 ≤2 卖点""字号 ≤3 级"等量化约束可参考，但东南亚视觉的**本地化四层、尺码对照、COD 说明、认证呈现**是抖音完全没有的硬要求。

---

## 1. 岗位定义与考核指标

### 岗位定位
TikTok 出海业务的**商品视觉前端产出者**，对点击率与转化率负责，**并通过降低退货率直接贡献利润**。

### 考核指标

| 指标 | JD 频次 | 说明 | 东南亚特有 |
|---|---|---|---|
| **品牌视觉一致性与规范遵守** | 9/40 (22%) | 最常被写成"隐性 KPI"：整套图看起来像不像一个品牌 | 多站点多语种下，"像不像一个品牌"要靠模板库锁 |
| **A/B 测试与素材迭代** | 7/40 (17%) | 英文样本高频："test and iterate"、"A/B testing on creative" | 与投手共担素材迭代节奏 |
| **交付时效与响应速度** | 5/40 (13%) | 大促排期下的出图时效是硬约束 | 多站点排期并行 |
| **主图 / 产品图点击率** | 5/40 (12%) | 商品线核心指标 | 受本地化质量直接制约 |
| **直播封面 / 缩略图表现** | 3/40 (7%) | 封面点击与进播转化 | 东南亚靠联盟内容导流，封面更关键 |
| **多尺寸适配完成率** | 3/40 (7%) | 一套素材适配 TikTok/Shopee/Lazada/Amazon 各规格 | 多平台铺货刚需 |
| **详情页转化贡献** | 2/40 (5%) | 详情页跳出率、加购率 | COD 说明与尺码对照影响转化 |
| **退货率改善** | — | **东南亚视觉最独特的价值指标** | COD 单退货 35–45%，退货不退佣金与平台费 |
| 本地化一次通过率 | — | 四层本地化质量 | 直译味是主要扣分项 |
| 多语种素材产出效率 | — | MCN 口径核心 | |
| 素材复用率 / 模板库覆盖度 | — | 资产化能力 | |

**与抖音美工岗考核结构的差异（不可互换）**：抖音侧美工的指标重心是**主图点击率 + 详情页转化率 + 店铺体验分/DSR**；TikTok 侧 40 篇 JD 里**排第一的是"品牌视觉一致性"（22%）——一个隐性 KPI**，排第三的是 **A/B 测试与素材迭代（17%）**。这意味着东南亚美工不只是出图执行岗，还要**建品牌视觉规范与模板库**（多站点多语种下这是唯一能保证一致性的办法），并且**素材要能被迭代**——而不是出一套图就结束。

### 硬性任职门槛
- **学历**：本科及以上偏主流（海外岗通常高于国内）
- **经验**：1–3 年为主；有跨境/出海视觉经验者优先
- **软件**：**PS（必需）**、AI；Figma（协作）；CDR/C4D/AE 为加分；Canva 适配小团队
- **语言**：英语硬要求；本地语言强加分
- **作品集**：需体现**电商转化导向**的作品，**尺码对照与多语种版本**是加分项
- **跨文化协作**：能与中国总部 + 本地团队协同

## 2. 四层本地化视觉规范

> 项目模板：`templates/美工设计/主图需求单.md`（需求单，含四层本地化核验栏）、`templates/美工设计/详情页结构模板.md`（详情页，含东南亚必加 5 项疑虑）、`templates/美工设计/视觉验收清单.md`（交付验收，含 TikTok 专项）

### 第 1 层：语言
- 主图卖点文案、详情页全部文字**母语者校对**
- 不得使用机翻或 AI 直译
- 术语用当地消费者实际在用的说法
- **检查标准**：本地人看完会不会觉得"这是翻译的"？

### 第 2 层：货币与度量衡
- 金额换算为当地货币，**注明汇率口径与时点**
- 尺码、重量、容量换算为本地常用单位
- **定价心理适配**：印尼客单价 $5–15、泰国 $10–30 → **同一商品不同站要重新定价，不是换算**

### 第 3 层：场景与模特
- 使用场景符合本地真实生活场景
- 模特肤色、体型、妆容符合当地审美
- 道具、包装、背景符合当地习惯
- 确认本地文化禁忌场景

### 第 4 层：文化符号
- 无中国特有元素、梗、手势
- 节日与场景表述符合当地语境
- 品牌与代言人如为本地形象需授权确认

### 核验表

| 层 | 检查项 | 通过标准 | 确认人 |
|---|---|---|---|
| 语言 | 主图文案 | 母语者校对签字 | 本地团队/达人 |
| 语言 | 详情页全部文字 | 与主图术语一致 | 本地团队 |
| 货币 | 金额 | 已换算 + 汇率口径时点 | 运营 |
| 货币 | 单位 | 本地常用 | 运营 |
| 货币 | **定价策略** | **按站重新定价，非换算** | 选品+运营 |
| 场景 | 使用场景 | 符合本地真实生活 | 本地团队 |
| 场景 | 模特/审美 | 符合当地审美 | 本地团队 |
| 符号 | 元素与梗 | 无中国特有元素 | 本地团队 |
| 符号 | 认证展示 | 本地类目要求已核 | 运营 |

## 3. 尺码对照与 COD 说明（本岗位在东南亚的核心设计职责）

### 3.1 为什么这是视觉岗的活

COD 退货率 35%–45%，而**退货只退买家全款，达人佣金与平台费不退回**。退货的直接诱因是"买错尺码"和"与预期不符"——**这两件事都是商品页该解决而没解决的**，所以归视觉。

### 3.2 尺码对照必备内容

| 项 | 要求 |
|---|---|
| **真人上身对照** | 不同身高/体重参考 → 建议区间 |
| **尺寸表** | 平铺尺寸 + 关键部位标注 |
| **模特参数** | 身高、体重、试穿尺码（消除歧义） |
| **尺寸对照表视频** | 评估是否需要（实测可降退货约 7%） |
| **通用规格说明** | 若为 S-XXL 通用款，明确写出并作为卖点 |
| **色差提示** | 批次色差坦诚说明 |

### 3.3 COD 说明必备内容

| 项 | 要求 |
|---|---|
| **支付方式** | 明确"仅支持货到付款（COD）" |
| **时效预期** | 本地仓 3–7 天 |
| **拒收后果** | 坦诚说明拒收会影响后续购买权限（实测可显著降低拒收率） |
| **本地退换政策** | 与 TikTok 本地客服体系一致的政策说明 + 联系方式 |
| **本地客服渠道** | 不用国内客服话术 |

## 4. 类目认证呈现

| 类目 | 需呈现的资质 |
|---|---|
| 化妆品/个护 | 本地化妆品注册/备案编号、成分合规说明、功效宣称依据 |
| 食品 | 进口许可/注册、清真认证（印尼市场重要）、成分表 |
| 电器 | 认证标识、电压适配（110V/220V 差异）、能效标识 |

**认证是上架前置条件**，缺失会导致下架或扣分。视觉上必须预留展示位与足够清晰度。

**印尼特别注意**：清真（Halal）认证在印尼市场是强需求，缺认证会显著降低转化。

## 5. 主图与详情页规范

### 5.1 主图五槽位 + 量化约束

| 槽位 | 内容 | 东南亚要点 |
|---|---|---|
| ① 商品特点 | 是什么 | 本地语言 |
| ② 优势 | 比别人好在哪 | **结合通用规格/易用性** |
| ③ 利益点 | 用户收益 | 可含价格机制，需本地货币且与实际一致 |
| ④ 证明 | 销量/评价/资质/检测 | **认证是东南亚高权重项** |
| ⑤ 场景 | 使用画面 | **必须是本地真实场景** |

量化约束：**单图核心卖点 ≤2 个；字号层级 ≤3 级。**（沿用 JD 的系统化规范精神）

### 5.2 详情页疑虑清单（东南亚版）

标准 8 项 + 东南亚必加 5 项：

**标准 8 项**：这是什么/适合我吗、质量好不好、规格合不合适、怎么用、值不值、售后保障、什么时候到怎么退、为什么别人买

**东南亚必加 5 项**：
1. **尺码怎么选**（真人上身 + 尺寸表）
2. **怎么付款**（仅支持 COD/货到付款）
3. **本地退换政策与联系方式**
4. **发货与到达时效**（3–7 天）
5. **认证与资质**（类目相关）

## 7. 常见错误与雷区

| 错误 | 后果 | 正确做法 |
|---|---|---|
| **只翻译文案不做四层本地化** | 点击率起不来 | 逐层核验，母语者校对 |
| **缺尺码对照** | COD 退货飙升，直接亏钱 | 真人上身 + 尺寸表 + 模特参数 |
| **没写 COD 说明** | 买家不知情 → 拒收 | 详情页明示支付方式与拒收后果 |
| **只做货币换算不做定价重算** | 价格无竞争力 | 按站重新定价 |
| **缺认证展示** | 下架或扣分 | 预留展示位并核类目要求 |
| **缺本地退换政策与联系方式** | 售后纠纷，拒收 | 按 TikTok 本地客服体系呈现 |
| **承诺做不到的时效** | 超时赔付 10% | 与 3-7 天实际一致 |
| **AI 生成商品图与实物不符** | 投诉仲裁，赔付可达订单金额 150% | 材质尺寸用实拍 |
| **AI 换脸** | 违规 | 绝对禁止 |
| **多语种版本术语不统一** | 体验割裂 | 维护多语种术语表 |
| **不回收退货率数据** | 视觉失去反馈闭环 | 上线后回收 CTR/转化/退货率并回写规范 |
| **单图讲三件事** | 缩略图无重点 | ≤2 核心卖点 |
| **自己检查自己** | 漏掉习惯性错误 | 他人复检 |
| **不沉淀模板** | 出图效率上不去 | 规范/模板/素材库持续维护 |

## 9. 数据与规则的时效性规范

- **类目认证要求、进口政策、平台审核规则**：变动频繁，**发布前必须重新确认**，标注来源与时点。
- **本地审美与流行趋势**：时效性强，不引用历史结论。
- **汇率**：注明换算时点；跨周期对比需说明汇率变动影响。
- **数据通道权威源**是项目 `docs/knowledge/data-channel.md`；取数走项目 `data-pipeline/` 下的采集器。**抖音侧零凭据通道已完全跑通**：热榜（`douyin_public.py`）+ 推荐流/话题真实体量/创作者画像/作品详情/评论（`douyin_feed.py`，推荐流自举，不需要种子 ID、不需要登录、不需要分享链接）。TikTok 侧采集器代码就绪，需 API token。外部数据只用于趋势与竞品判断，**经营口径（结算/真实退货/实收）必须来自店铺后台**。
- **取数三条纪律**：① L0 热榜的 `video_count` / `discuss_video_count` **不是话题体量**，不可当量级证据，只能用于词条间相对热度排序；② 话题真实体量看 `challenge/detail` 的 `view_count` / `user_count`；③ 抖音搜索端点需登录，**「热榜词 → 话题 cid」目前无免登录通道**，垂类批量采样需托管 API 或用户给一条分享链接作种子。
- **平台知识库权威源**是项目 `docs/knowledge/platform-model.md`；与最新公告冲突以公告为准并立即更新。
- **退货率口径**：COD 单退货率与综合退货率需分开，不可混用。
