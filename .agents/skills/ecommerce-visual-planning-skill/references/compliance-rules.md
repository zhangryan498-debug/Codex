## 零层：通用规则（所有产品必过）

### 1. 绝对化用语

【法】《广告法》第九条第三项禁止使用「国家级」「最高级」「最佳」及其他含义相同或近似的用语。

**执法口径以《广告绝对化用语执法指南》为准**（市场监管总局 2023 年 3 月发布，2023 年 2 月 24 日总局第 3 次局务会议审议通过）：
<https://www.samr.gov.cn/ggjgs/tzgg/art/2023/art_183b5cb48d9e4f0dba67f9f912a913ba.html>

#### 不视为违规的情形 ⚠️ 电商实务中经常被过度自我审查

指南第五条、第六条列了豁免情形。**知道这些能少删很多本来合法的文案：**

| 情形 | 举例 |
|---|---|
| 仅表明服务态度、经营理念、企业文化、主观愿望 | 「为您提供最好的服务」（指向服务态度而非商品性能） |
| 仅表达经营者目标追求 | 「做最好的自己」 |
| **仅用于同一品牌/同一企业商品的自我比较** | 「本店销量最高的一款」 |
| 仅用于使用方法、使用时间、保存期限等消费提示 | 「最佳赏味期 30 天」 |
| 依据国家/行业/地方标准的商品分级用语 | 「特级初榨」（有标准依据时） |
| 商品名称、规格型号、注册商标、专利中含绝对化用语 | 品牌名本身带「第一」 |
| 依据国家有关规定评定的奖项、称号 | 官方评定的称号原文 |
| **限定具体时间、地域等条件下，表述客观时空顺序或销量、销售额、市场占有率等事实信息** | 「2025 年双十一本类目销量第一」（须有可核查来源） |

【推】即便属于豁免情形，**电商平台的系统审核未必按指南的细粒度判断**，可能仍会拦截。稳妥做法是保留证据、准备申诉材料，而不是假定一定能过。

#### 仍应规避的禁用清单

```
最、最佳、最好、最优、最低价、最便宜、最新、最先进
第一、唯一、独家、首创、开创、领导者、领先、冠军
国家级、世界级、顶级、极致、终极、完美、无敌
绝对、彻底、完全、100%、永久、永不、万能、包治
```

**替换方向：**

| ❌ | ✅ |
|---|---|
| 最好用 | 多数用户选择 / 好评较多 |
| 第一品牌 | 行业内较早从事 / 品牌之一 |
| 100% 有效 | 有助于 / 多数情况下 |
| 彻底解决 | 显著改善 / 逐步改善 |
| 独家专利 | 已获专利（附专利号） |

【推】比较级也可能被判定为绝对化，如「行业最强」「同类最优」。安全做法是**只陈述自身属性，不做排名式表述**。

### 2. 数据与事实宣称必须有背书

【法】《广告法》第二十八条、《反不正当竞争法》第八条禁止虚假或引人误解的宣传。

**具体口径以《广告引证内容执法指南》为准**（市场监管总局，成文 2026 年 6 月 3 日，发布 2026 年 6 月 12 日）：
<https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/ggjgs/art/2026/art_8962fc1e4eb44a87b93d265af43b6940.html>

#### 五项硬性要求（条文原文摘录）

| 条 | 要求 | 原文 |
|---|---|---|
| **第四条** | 出具机构资质 | 出具相关实验结论、测量结果或者检验检测数据的机构应当具有相应的**法定资质、专业能力** |
| **第五条** | 方法科学性 | 应当通过科学方法取得，其统计和调查范围应当具有**广泛性、合理性**。采用抽样方式的，样本应当符合**科学性、代表性**要求 |
| **第六条** | 内容一致性 | 广告引证内容应当准确，并与其所依据的实验结论、测量结果、检验检测数据等的**意思表达一致** |
| **第八条** | 表明出处 | 依法应当**如实表明引证内容的出处**。出处包括开展实验、测量、检验检测机构名称或文献资料的题目及著者名称等信息 |
| **第九条** | 适用范围/有效期 | 广告引证内容有**适用范围和有效期限**的，应当按规定明确表示 |

#### 落到电商文案

- 「24 小时保温」→ 须有检测机构名称 + 报告编号 + **测试条件**（初始水温、环境温度、容量），否则删除
- 「XX 倍」「XX%」「未检出」→ 同上
- 认证宣称 → 认证机构全称 + 证书编号
- 「销量第一」「XX 万人选择」→ 可核查的统计来源 + **统计期间和范围**（呼应绝对化用语指南第六条的豁免条件）
- 无支撑的数据 → **删除**，或改为不含数值的定性描述

【推】「实验室数据」「内部测试」不能作为对外宣称依据，除非同时公开测试条件和机构资质——按新指南，机构资质是硬要求，自测基本不满足。

### 3. 竞品对比

【法】《反不正当竞争法》第十一条禁止编造、传播虚假信息损害竞争对手商誉。

- **不直接点名贬低竞品品牌**
- **不做「我优他劣」的二元对立**
- 正确方式：陈述自身参数 + 引用行业公开标准/基准做客观参照
- 对比必须**同条件**（同规格、同测试方法），并标注对比条件

### 4. 医疗化暗示（非医疗类产品通用红线）

【法】《广告法》第十七条：除医疗、药品、医疗器械广告外，禁止其他广告涉及疾病治疗功能，不得使用医疗用语或易使商品与药品、医疗器械相混淆的用语。

**这条适用于绝大多数普通商品**，是最容易被忽视的红线。

| ❌ 禁止 | 示例 | ✅ 方向 |
|---|---|---|
| 疾病名称 | 失眠、便秘、湿疹、颈椎病、三高 | 全部删除，不得关联 |
| 症状描述 | 疼痛、发炎、过敏、水肿 | 改为中性感受描述 |
| 治疗动词 | 治疗、根治、修复、康复、消炎、杀菌（无资质） | 清洁、护理、养护、改善 |
| 医疗身份 | 医生推荐、临床验证、药用级、医疗级（无资质） | 删除，或改为「专业」「科学」 |
| 人群疾病绑定 | 适合糖尿病人、三高人群专用 | 删除 |

### 5. 效果表述弱化

【推】所有效果类表述添加弱化词：**助力 / 有助于 / 辅助 / 逐步 / 因人而异**。

- ❌ 「用完就白」「一次见效」「保证有效」
- ✅ 「有助于提亮肤色」「效果因人而异」

### 6. 画面构成的宣称 ⚠️ 最易漏

【推】**宣称不只由文字构成，画面同样构成宣称。** 删掉违规文案但保留等价画面，风险没有降低。

电商视觉尤其容易踩这条：文案审得很干净，画面却在说同一件事。

| 画面手法 | 实际构成的宣称 | 等价的违规文案 |
|---|---|---|
| 早晨装水 → 傍晚仍冒热气 | 保温时长承诺 | 「24 小时保温」 |
| 使用前皮肤暗沉 → 使用后透亮 | 功效承诺 | 「7 天美白」 |
| 体重秤数字变化 | 减重效果 | 「一个月瘦 X 斤」 |
| 人物皱眉捂腰 → 舒展微笑 | 症状改善 | 「缓解腰痛」 |
| 显微镜下细菌消失 | 杀菌功效 | 「杀菌率 99%」 |
| 白大褂人物出镜 | 医疗背书 | 「医生推荐」 |
| 奖杯、榜单、第一名领奖台 | 排名宣称 | 「行业第一」 |
| 检测报告样式的图形（无真实编号） | 认证背书 | 伪造检测报告 |

**核查方法**：把每张图的画面内容翻译成一句陈述句，再用文案的标准审这句话。**画面说了什么，就当它写了什么。**

- ✅ 通过：「这是一个 500ml 的不锈钢杯子放在办公桌上」
- ❌ 拦截：「这个杯子从早上到傍晚都能保温」

**素材真实性另见第 7 条**：画面说得对，还要画面是真的——AI 图不能承载工艺宣称。

**对比类画面的额外要求**：任何前后/时间对比画面，必须与文案同等对待——需要测试条件和数据来源，否则改为不含时间轴的静态展示。

### 7. AI 图 / 渲染图不能承载工艺宣称 ⚠️ 生图工作流特有

【法】《广告法》第二十八条：商品的性能、功能、质量、规格、成分等信息**与实际情况不符**，对购买行为有实质性影响的，属虚假广告。

**AI 生成图和 CG 渲染图不是实物。** 用它们做视觉可以，但**图上那些"看起来做工很好"的部分不能拿来当卖点写**——实物开模出来达不到，就是与描述不符。

#### 分界

| 可以用 AI / 渲染图 | 必须实拍 |
|---|---|
| 情绪表达、氛围场景 | **工艺细节特写**（分色、边缘、接缝、走线） |
| 概念展示、世界观 | **材质质感**（光泽、纹理、手感） |
| 系列构成示意 | **尺寸参照**（与手/桌面/常见物对比） |
| 包装设计预览 | **色彩还原**（买家会拿到手比对） |

#### 高危品类

| 品类 | 买家最会比对的 |
|---|---|
| **潮玩 / 手办** | 涂装还原度、分色精度、毛边——**本品类投诉量第一** |
| 服装 | 面料垂感、实际颜色、版型 |
| 食品 | 份量、成品样态、摆盘 |
| 家具 / 家居 | 木纹、做工、实际色差 |

#### 落到文案的硬规则

AI 图上**不得**出现这类宣称，除非有对应实物：

```
精细分色、边缘干净利落、多层涂装、色彩饱满、
工艺精湛、质感高级、还原度高、细节丰富
```

**处理方式（三选一）：**

1. **出样品后用实拍替换**——推荐，尤其是细节特写图
2. 保留 AI 图但**删掉工艺宣称文案**，只做情绪/概念表达
3. 图上**显著标注「概念图，以实物为准」**

> 与规则库零层第 6 条「画面构成的宣称」配合看：第 6 条管**画面说了什么**，本条管**画面是不是真的**。两条都过才算干净。

【验】部分平台对主图有「实物图」要求，尤其是非预售商品。**以你的商家后台类目规则为准**，我这边查不到官方条文。

### 8. 引用来源分级 ⚠️ 联网查证时必读

允许联网查证规则，**但来源等级决定了结论能有多硬**。用错来源，等于把【验】伪装成【法】。

| 结论类型 | 只接受的来源 | 不接受 |
|---|---|---|
| 法律法规 | 全国人大、国务院、市场监管总局官网；地方市场监管局；官方媒体转载 | 律所营销文、自媒体解读 |
| 平台规则 | **平台官方规则中心 / 商家后台帮助中心**（rule.taobao.com、卖家后台、京东商家帮助中心等） | 设计工具博客、电商代运营站、第三方"卖家网"类站点、SEO 聚合页 |
| 检测/认证标准 | 标准发布机构、认证机构官网 | 商品详情页、供应商宣传材料 |

**硬性要求：**

- 引用平台规则时**必须标注来源域名**，让用户能自行核对
- 来源不属于上表白名单 → 结论降级为「未验证参考」，明确写出「以你的商家后台最新规则为准」
- **查不到官方来源时，说「查不到」**，不要用第三方站点凑数
- 平台规则更新频繁，任何查证结论都附时效提示

> 反例：用设计工具的博客文章作为「淘宝主图尺寸规则」的依据。那是二手整理，可能过时、可能本身就抄错。**正确做法是标注为未验证参考，并让用户查商家后台。**

### 9. 平台差异

【验】**以下为待验证项，未经你自己核实前不要当作事实使用。** 各平台规则更新频繁，请以商家后台最新版《禁售/违禁信息规则》为准。

| 平台 | 需自行核实的重点 |
|---|---|
| 淘宝 / 天猫 | 系统自动敏感词拦截范围；特殊品类资质要求 |
| 京东 | 参数页与资质一致性要求；功效宣称容忍度 |
| 拼多多 | 价格类绝对化表述的判定标准 |
| 抖音小店 | 视频/直播口播是否同标准审核 |

> 补充这张表的正确方式：把你自己被驳回过的具体案例记进来，标为【验】，写清平台、时间、原文、驳回理由。**不要凭推测填写。**

## 品类层 A：普通食品（非保健食品、非药品）⚠️ 最严

### 核心原则

【法】《食品安全法》第七十三条、《广告法》第十七条：**普通食品广告不得涉及疾病预防、治疗功能。**

**关键认知：保健食品至少有批准文号可以说对应功能，普通食品什么功能都不能说。** 这一点最反直觉，也最容易踩。

### 绝对禁止

| ❌ 类型 | 示例 | 为什么 |
|---|---|---|
| 功效暗示 | 「喝走胀闷感」「喝出好状态」「日常调理」 | 暗示身体变化即功效宣称 |
| 症状关联 | 先描述胃胀/失眠/疲劳，再接产品 | 痛点 + 产品 = 间接功效联想 |
| 疾病人群绑定 | 「适合糖尿病患者」「三高人群」 | 将产品与疾病绑定 |
| 身体变化承诺 | 「喝了之后 XX」「坚持饮用能 XX」 | 效果承诺无依据 |
| 原料功效转嫁 | 「XX 富含 YY 成分 → 所以能 ZZ」 | 用原料暗示成品功效 |
| 保健功能词 | 增强免疫、改善睡眠、抗氧化、排毒 | 属保健食品功能范畴 |

### 安全表达白名单（只能说这些）

| ✅ 可以说 | ✅ 可以说 | ✅ 可以说 |
|---|---|---|
| 原料来源与产地 | 工艺特点（速溶/无渣/冷萃） | 口感风味描述 |
| 配料表内容 | 营养成分数据（需检测报告） | 食用场景与时机 |
| 包装规格/便携性 | 品牌故事/供应链把控 | 生产资质/许可证号 |

### 兜底声明

```
本品为普通食品，非保健食品，非药品。
不具有保健功能或治疗作用。
```

## 品类层 B：保健食品（持有保健食品批准文号）

### 核心铁律

【法】《广告法》第十八条：保健食品广告不得涉及疾病预防、治疗功能；不得声称或暗示为保障健康所必需；**必须显著标明「本品不能代替药物」**。

**只能宣传批准文号载明的功能名称，一个字不多、一个字不少。**

操作方法：
1. 先取得该产品批准文号的**功能原文**
2. 全文只允许出现该功能的**标准表述**，不得同义替换、不得扩展

### 功效边界

| ❌ 禁止类型 | 禁用词举例 | 处理 |
|---|---|---|
| 美容护肤 | 气色、素颜、美容、养颜、抗衰、嫩肤 | 非批准功能则全部删除 |
| 血糖相关 | 降血糖、稳血糖、控糖友好、糖友可吃 | 删除；涉及疾病，任何批文都不能说 |
| 上火清热 | 不上火、祛火、清热、解毒 | 删除或改为口感描述 |
| 免疫睡眠 | 提高免疫力、改善睡眠 | 仅当为批准功能且用标准表述时可用 |
| 减肥体重 | 瘦身、减脂、燃脂 | 仅当批文为「减肥」功能时用标准表述 |

### 必须保留的声明

```
本品为保健食品，不能代替药物。
不能代替药物治疗疾病。
具体功效以批准文号载明内容为准。
```

## 品类层 C：化妆品

### 核心规则

【法】《化妆品监督管理条例》：化妆品不得明示或暗示具有医疗作用；禁止使用「医学」「处方」「药妆」「医美」等表述。特殊化妆品（染发、烫发、祛斑美白、防晒、防脱发）须经注册，宣称须与注册内容一致。

| ❌ 禁止 | ✅ 方向 |
|---|---|
| 药妆、医学护肤、械字号（无资质） | 删除 |
| 消炎、杀菌、抑菌（无资质）、抗敏 | 舒缓、清洁、护理 |
| 祛痘、去疤、生发 | 改善外观状态类中性表述 |
| 美白（无特证） | 提亮肤色（仍属风险区，须有特证方可宣称美白） |
| 干细胞、基因、纳米（无依据） | 删除 |

【推】功效宣称须有功效评价资料支撑。「7 天见效」类时效承诺应有测试报告并标注测试条件与样本量。

## 品类层 D：运动器材 / 体态管理（非医疗器械）

### 核心风险

目标用户本身就有身体困扰，极易触碰「医疗化暗示」红线。

| ❌ 禁止类型 | 禁用词举例 | ✅ 替换 | 原因 |
|---|---|---|---|
| 痛感描述 | 腰酸背痛、颈椎痛、关节痛 | 腰背不适、肩颈紧绷感 | 「痛」属病理症状 |
| 医学术语 | 骨盆前倾、脊柱侧弯、椎间盘 | 体态不佳、背部线条不直 | 暗示诊断 |
| 治疗动词 | 修复、治疗、康复、矫正 | 体态管理、锻炼、训练 | 暗示治病 |
| 效果承诺 | 恢复 XX、找回 XX | 向 XX 靠近、改善当前状况 | 绝对化承诺 |
| 专业宣称 | 专业级、医疗级（无资质） | 科学、系统、规范 | 无资质不可宣称 |

### 声明模板

```
本产品为运动器材，非医疗产品。
不能治疗疾病或病理问题。
训练效果因人而异，建议在专业人员指导下使用。
如有身体不适请及时就医。
```

## 品类层 F：潮玩 / 盲盒 / 手办

### 驱动力归属

【推】潮玩主型为**情感价值型**，次型视觉驱动型。用户买的是 IP 情感、收藏欲和开箱仪式感，不是功能。

对应到主图分配：情感价值型的默认表是照香氛礼盒设计的（KV5「赠礼行动」对盲盒不适用），**潮玩用 SKILL.md Step 4 的「品类特例」表**：情绪截流 / 系列全貌 / 开箱仪式 / 工艺质感 / 概率与行动。

其中 **KV3 开箱仪式**不是可选项——盲盒的开箱瞬间就是产品本身。

### F-1 盲盒专项：信息披露 ⚠️ 硬性

【法】《盲盒经营行为规范指引（试行）》，2023 年 6 月 7 日市场监管总局第 10 次局务会议通过：
全文（市场监管总局印发通知）：
<https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/zfjcs/art/2023/art_e2facd76a7fb4e90b03912cffb5e7d53.html>

**必须以显著方式对外公示：**

**第九条**要求以显著方式公示、保证消费者购买前知晓的共**八项**：

| 必须公示 | 落到详情页 |
|---|---|
| 商品名称 | 系列名与款式名 |
| 商品种类 | 材质、类型 |
| 商品样式 | 每款外观 |
| **抽取规则** | 抽取方式、是否可换 |
| **商品分布** | 每款在一端/一箱中的分布 |
| **限量商品投放数量** | 限量款须写明投放量 |
| **抽取概率** | **隐藏款概率必须写明**，不能只说「稀有」 |
| **商品价值范围** | 盒内物品的价值区间 |

**第九条同时禁止：**

- 通过**后台操纵改变抽取结果**、随意调整抽取概率等方式变相诱导消费
- 以折现、回购、换购等方式拒绝或故意拖延发放盲盒
- **设置空盒**

**第十条**另要求建立生产经营记录制度：保留抽取概率设定，建立出厂概率抽检机制；线上即时开盒的还须保留完整抽取记录与追踪记录。

> 「概率必须公示」意味着**详情页必须有概率模块**，这不是转化设计选择，是法定义务。
> 在模块池里对应 M7 信任证据 + M8 参数规格，潮玩品类**两者都是必选**。

### F-2 盲盒专项：禁止的文案表达

由信息披露义务和《广告法》第九条、第二十八条推出：

| ❌ 禁止 | 违规类型 | ✅ 替代 |
|---|---|---|
| 必中隐藏款、100% 出货、包中 | 绝对化 + 虚假宣传 | 公示真实概率数字 |
| 欧皇必备、非酋退散（暗示可控概率） | 引人误解 | 删除，或明确写「概率固定，与运气无关」 |
| 稳定升值、收藏增值、二级溢价 X 倍 | **炒作二级市场** | 删除。指引明确要求经营者承诺不炒作、不直接进入二级市场 |
| 一箱必出、端箱包隐藏 | 若无端盒保证机制则属虚假宣传 | 有明确机制才可写，并写清机制 |
| 划线价非真实成交价 | **虚假折扣** | 划线价须为真实成交价 |

【法】上海市《盲盒经营活动合规指引》另有更细口径（地方性，供参考）：盲盒商品实际价值应相当于或低于成本加合理利润；**价差不应超过 200 元**；明令禁止虚假宣传和虚假折扣。
<https://fw.scjgj.sh.gov.cn/alc/standard/mh.jsp>

### F-3 盲盒专项：未成年人

【法】同上指引：

**第二十三条**：

- **不得向未满 8 周岁未成年人销售盲盒**
- **向 8 周岁及以上未成年人销售，应当依法确认已取得相关监护人的同意**
- **应当以显著方式提示** 8 周岁及以上未成年人购买盲盒需取得相关监护人同意
- 须采取有效措施防止未成年人沉迷，在解决未成年人消费争议方面提供便利

> 后两条常被忽略。**「不得向未满 8 周岁销售」不等于 8 周岁以上就可以随便卖**——既要确认监护人同意，还要在页面上**显著提示**。这是详情页必须有的模块，不是可选项。

**落到视觉：**

- 详情页须标注适用年龄，位置显著
- **不得使用低幼化视觉语言吸引儿童**（卡通化过度、儿童模特、校园场景）
- 不得出现「学生党必入」「零花钱就能买」这类指向未成年人的表达

### F-4 负面清单：不得以盲盒形式销售

【法】药品、医疗器械、活体动物、易燃易爆物品。化妆品、食品有限定性要求。

**做联名盲盒时尤其注意**——潮玩 × 食品、潮玩 × 美妆的联名款受此限制。

### F-5 玩具属性与 3C 认证 ⚠️ 分界点

【推】这是潮玩品类最容易出事的分界：

| 定位 | 监管 | 视觉要求 |
|---|---|---|
| 标注为**玩具**、适用 14 岁以下 | 适用 GB 6675 玩具安全国标，需 **3C 认证** | 无 3C 不得宣称玩具属性 |
| 标注为**15 岁以上收藏品 / 摆件**，非玩具 | 可不适用玩具类监管 | **但不得用儿童向视觉营销**，否则可能被认定为实际面向儿童 |

**不能两头占**：标着「15+ 收藏品」规避 3C，画面却全是儿童玩耍场景，这个组合风险最高。

### F-6 IP 授权 ⚠️ 潮玩最大的实际风险

【推】潮玩的头号法律风险不是广告法，是**著作权和商标侵权**。

- 视觉中**不得出现未授权的 IP 形象**——动漫角色、影视形象、他人原创设计
- 「XX 风格」「致敬 XX」不构成授权，仍可能侵权
- 联名款须有授权文件，主图可标注授权信息但**须与授权范围一致**
- 生图 Prompt 中**不得引用受版权保护的角色名或艺术家名**

> 本 SOP 不做侵权判断。发现视觉方向可能涉及未授权 IP 时，标注风险并要求用户确认授权文件，不代为判断是否构成侵权。
