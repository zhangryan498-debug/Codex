# 电商视觉策划 Skill

把产品资料变成能直接交给设计师开工的主图 / 详情页方案：画面描述、图内文案、设计说明、生图 Prompt，外加一份合规风险清单。

[English](README.en.md)

---

## 它解决什么问题

直接让 AI「写一套主图文案」，通常会得到三样东西：卖点堆砌、参数复制粘贴、以及一堆过不了平台审核的绝对化用语。

这个 Skill 加了三层约束：

1. **先判断转化驱动力，再动手**。美妆和电钻的主图逻辑完全不同，不能套同一个模板。
2. **两道确认门**。策划案确认一次、Storyboard 确认一次，方向错了在一行字的阶段就拦住，不等到出完稿再返工。
3. **合规按法律基线判断**，并且明确标注哪些是法条、哪些是推导、哪些待你自己验证。

## 和常见做法的区别

| | 常见做法 | 本 Skill |
|---|---|---|
| 主图任务 | 固定 5 张模板 | **按驱动力分配**，四种驱动力四套任务 |
| 详情页模块 | 固定 9 模块全上 | **按驱动力裁剪**，控制在 6–9 个 |
| 自审 | 给个总分 | 五维独立评分，**任一维 <80 单独重写** |
| 扣分 | 只给分数 | **必须指到具体位置**，否则视为未执行 |
| 合规 | 敏感词表 | 分层规则库 + **来源等级标注**（法/推/验） |

## 怎么用

装完后直接说：

```
帮我做一套主图和详情页，产品是 XXX，平台是淘宝
```

它会先问你缺的关键信息（最多 3 个问题），然后走完整流程。

**你会经历两次暂停**，这是设计如此：

- 第一次：确认转化驱动力和风格锁
- 第二次：确认主图任务分配和详情页模块顺序

想跳过就直接说「按你判断直接出终稿」。

### 典型触发语

```
这个产品怎么提炼卖点做主图
先给我 storyboard，方向对了再写文案
设计师要开工，给画面 + 图内文案 + 设计说明
帮我看看这套详情页有没有广告法风险
按抖音小店风格出一套视觉脚本
```

## 输出什么

```
1. 策划案回顾（驱动力 / 风格锁 / 合规边界 / 假设）
2. 主图 5 张   — 每张：画面 + 图内文案 + 设计说明 + 生图 Prompt
3. 详情页模块  — 每个：画面 + 图内文案 + 设计说明 + 生图 Prompt
4. 五维自审评分（含扣分位置和修改动作）
5. 合规风险清单（命中项 + 风险类型 + 依据 + 建议处理）
6. 待补充信息
```

## 合规规则库

[references/compliance-rules.md](references/compliance-rules.md) 按品类分层：

- **零层通用**：绝对化用语、数据背书、竞品对比、医疗化暗示、效果弱化
- **品类层**：普通食品（最严）/ 保健食品 / 化妆品 / 运动器材 / 数码家电 / **潮玩盲盒**

每条规则标注来源：

| 标记 | 含义 |
|---|---|
| 【法】 | 法律法规明文规定，**附条号与官方链接** |
| 【推】 | 由法条推导的实操做法 |
| 【验】 | 需实操验证的平台细则，**未验证前不当作事实** |

平台规则那部分目前大多是【验】。正确的补充方式是把你**自己被驳回过的真实案例**记进去，而不是凭推测填表。

【法】条目已逐条比对官方原文（广告法、食品安全法、绝对化用语执法指南、引证内容执法指南、盲盒经营行为规范指引），附条号和 gov.cn / samr.gov.cn 链接，可自行核对。

[examples/blind-box-case.md](examples/blind-box-case.md) 是一次完整跑通的记录——潮玩盲盒，从产品资料到可用的生图 Prompt，含三处判断说明：为什么改 KV3、为什么 KV4 不能做 IP 背书、以及「AI 图不能承载工艺宣称」这条规则是怎么从实操里发现的。

## 已知限制

六轮实测下来的边界，如实写在这里：

**1. 格式型约束推不动**


| 稳定生效 | 稳定失效 |
|---|---|
| 合规红线（编造/绝对化/功效/炒作/未成年人/IP） | 任务名逐字复制 |
| 品类特殊义务（概率公示/监护人同意） | 字段填写要求 |
| 驱动力判断、风格锁、确认门暂停 | 固定格式的核对表 |

**左边是内容型规则，右边是格式型规则。** 内容型讲清了为什么，模型稳定执行；格式型只规定形式，模型会用自己认为更好的表达替代。

本 Skill 已按这个规律重写——去重、任务分配都改成了内容型判断（「这张图消除哪个顾虑」），不再要求填固定字段。**如果你要二次开发，别往格式约束上投入。**

**2. 说「跳过确认环节」会丢掉任务分配**

规避方法：不说那句话。正常走流程，或点名要 storyboard——实测点名要 storyboard 时输出完整。

**3. 联网查证的来源质量不稳定**

它会自己找依据。法规类通常能找到政府源，但**平台规则和 IP 法这类客观上没有公开官方文件的话题**，实测出现过引用律所文章、设计工具博客的情况。

规则库里已加「查不到官方依据就明说，不要用第三方站点填充权威感」，但不保证每次生效。**看到引用源不是 gov.cn / npc.gov.cn / samr.gov.cn 时，自行打折扣。**

## 边界

这个 Skill **不做**这些事，也请不要让它做：

- 出具法律意见，或替代平台审核结论
- 编造检测报告、专利、批准文号、销量、评价、认证
- 为无资质产品制造功效背书
- 自动上架、自动投放

**五维自审里的「合规性」分数是结构化自查，不是法律意见。** 上线前仍须走平台预审和资质核对。
