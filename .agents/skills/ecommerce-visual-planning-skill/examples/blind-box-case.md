# 案例：潮玩盲盒完整流程

一次完整跑通的记录，从产品资料到可用的生图 Prompt。

> **产品数据已做脱敏处理**——名称、款数、价格、尺寸均为虚构。**流程、判断和合规命中是真实的**，包括中途那次人工改动和它自己做出的两个决定。

这个案例值得看的地方不是最终文案，而是**中间的三个判断**：为什么改 KV3、为什么 KV4 不能做 IP 背书、以及一条规则是怎么从这次实操里被发现的。

---

## 输入

```
产品：咕噜猪 翻浪岛系列盲盒
款数：6 款常规 + 1 款隐藏
整端：13 盒
隐藏款概率：1/13
端盒规则：每端固定含 1 个隐藏款
材质尺寸：树脂，高约 12cm
价格：单盒 79 元，整端 1027 元
平台：淘宝
IP 归属：自有原创
商标：未查询
版权登记：无
```

**注意最后两行。** 它们决定了后面所有文案不能写「已登记」「独家授权」。

---

## Gate 1：视觉策划案

### 驱动力判断

**情感价值型（主）+ 视觉驱动型（次）**

依据：用户买的不是功能，是「治愈感、开盒惊喜、原创角色陪伴、收藏完整性」。主图先抓情绪和画风，详情页再补款式、概率、价格。

### 风格锁

| 项 | 设定 |
|---|---|
| 配色 | 雾霾蓝 / 奶油黄 / 薄荷绿（三色） |
| 产品占比 | 主图 55%–70% |
| 光影 | 柔和自然光，微光泽树脂反射 |
| 字体 | 圆润中粗黑体标题，几何数字 |
| **禁漂移** | 不做三丽鸥/吉卜力近似、不写未授权联名、不出现「必中隐藏款」「稳定升值」「学生党零花钱」 |

> **禁漂移项里混进了合规红线**，这不是 SOP 要求的。它把前面几轮压力测试的结论沉淀进了风格锁——而风格锁要传给每一张生图 Prompt，比放在合规清单里更管用。

### 合规边界

**可写**：原创 IP、6 常规 + 1 隐藏、隐藏概率 1/13、每端固定含 1 隐藏、单盒/整端价格、理性收藏

**不可写**：必中、必出、保值、升值、溢价、翻倍、投资、联名、官方合作、最治愈、全网第一、学生党零花钱、**已登记**

### 当前假设

1. 潮玩摆件类，不涉及食品/化妆品/儿童玩具强制认证
2. 「自有原创」有可核验依据，但**版权登记未完成**
3. 端盒固定含隐藏——**基于用户明确确认的规则**，非默认

## Gate 2：Storyboard

用的是[潮玩品类特例表](../SKILL.md)（情感价值型的默认表 KV5「赠礼行动」对盲盒不适用）。

### 它的初版

| # | 任务 | 第一落点 |
|---|---|---|
| KV1 | IP 截流 | 角色表情 + 名称 |
| KV2 | 系列全貌 | 6 常规 + 1 隐藏剪影 |
| KV3 | **端盒卖点** | 整端 13 盒、每端 1 隐藏 |
| KV4 | 材质尺寸 | 树脂质感、12cm |
| KV5 | 价格行动 | 单盒 79、整端 1027、**概率 1/13** |

### 我改了 KV3 和 KV5

**问题：KV3 和 KV5 回答的是同一个问题。**

两张都在讲「怎么买、什么规则」。按去重规则这就是重复，而代价很实：

**整套 5 张没有一张开箱图。** 盲盒的开箱瞬间就是产品本身，而端盒规则详情页已经用两个模块讲透了，主图再占一张是重复劳动。

改法：

| # | 改前 | 改后 |
|---|---|---|
| KV3 | 端盒卖点 | **开箱仪式** |
| KV5 | …概率 1/13 | …**每端 1 隐藏** |

概率 1/13 交给详情页 M5 公示（法定义务在详情页履行即可）。

改完 5 张分别回答：**角色打不打动我 / 有几款 / 拆盒什么体验 / 做工值不值 / 怎么买**——五个不同的顾虑。

### KV4 为什么不做 IP 背书

前几轮测试里，模型两次把潮玩的 KV4 从「工艺质感」改成「IP 背书 / 版权登记」。这次没有，因为规则库里补上了理由：

> 版权信息属于详情页 M7，主图再做一遍是浪费一张图。**盲盒用户看不到实物，涂装精度和毛边才是核心疑虑**——这张图不解决，M7 再权威也补不上。

**给理由比下命令有效。** 前两次「任务名不可改写」的硬性要求都没拦住，这次讲清了为什么就改对了。

## 执行稿：5 张主图

每张给了图内文案 + 生图 Prompt。文案遵守主图约束（≤5 行、单行 ≤6 字）。

### KV1 · 情绪截流
**回答：这个角色打动我吗？**

```
咕噜猪
翻浪登场

```

```
海岛搞怪潮玩盲盒主图，原创小猪角色，大头短腿圆肚，塌眼坏笑表情，

      写实猪、恐怖、水印、logo、杂乱背景
```

## 详情页模块

8 个模块，在 6–9 区间内：

| 模块 | 内容要点 |
|---|---|
| M1 首屏钩子 | 情绪先行，主角从浪花冒头 |
| M2 世界观设定 | 翻浪岛地图，建立 IP 记忆点 |
| M3 七款角色展示 | 6 常规统一角度，隐藏款半遮挡 |
| M4 端盒规则 | 13 格分布示意；建议标注每款常规 2 个、隐藏 1 个 |
| **M5 单盒概率说明** | **隐藏概率 1/13、不支持指定款**——法定义务 |
| M6 材质尺寸 | 树脂、约 12cm、桌面存在感 |
| M7 价格规格 | 单盒 79、整端 1027、**整端不承诺隐藏款** |
| M8 购买提示 | 随机发货、可能重复、理性收藏、**未成年人购买需监护人同意** |

> M4 建议的分布 2×6+1 = 13 ✓，M7 的 79×13 = 1027 ✓。数字自洽。

## 合规命中

| 命中 | 依据 | 处理 |
|---|---|---|
| 「单盒必中」「端箱必出」 | 与 1/13 概率冲突，属引人误解 | 拒绝；改为公示真实概率 |
| 「稳定升值」「二级溢价 3 倍」 | 盲盒指引要求不炒作、不直接进入二级市场 | 拒绝；**「这是事实」不构成理由** |
| 「学生党零花钱就能买」 | 第二十三条未成年人保护 | 拒绝；并指出与「18-30 岁女性」定位冲突 |
| 「联名款」「风格参考三丽鸥/吉卜力」 | 无授权即虚假授权；角色与场景表达受保护 | 拒绝；给出可用的通用审美元素清单 |
| 「已登记」 | 版权登记未完成 | 不写；建议上线前补商标近似查询与版权登记 |
| 抽取概率未公示 | 第九条 | 强制进 M5 |

## 这次实操发现的规则

出图之后发现了一条规则库原本没有的东西。

**成图上写着「精细分色」「边缘干净利落」「多层涂装 色彩饱满」，而实物还没开模。**

规则库当时有「画面构成的宣称」（管画面说了什么），但没有管**画面是不是真的**。AI 图上的工艺细节是渲染出来的，实物达不到就是与描述不符（《广告法》第二十八条）。

潮玩对这条尤其敏感——涂装还原度是本品类投诉量第一。

这条已补进[规则库零层第 7 条](../references/compliance-rules.md)：AI/渲染图可用于情绪、概念、系列示意，**工艺细节、材质质感、尺寸参照、色彩还原必须实拍**。

---

## 复盘

**跑通了什么**：产品资料 → 策划案 → storyboard → 执行稿 → 生图 Prompt → 可用的图。全程只有一处人工改动（KV3/KV5 去重）。

**验证了什么**：给理由比下命令有效（KV4 不再变成 IP 背书）；品类层的合规义务确实会落到模块选择上（M5 概率模块是法定义务，不是转化设计选择）。

**没跑通什么**：说「先跳过确认环节」时，任务分配会连同去重一起丢失。见 [README 已知限制](../README.md)。

**图片说明**：本案例不附成图。生图 Prompt 是可复用的产出，实测可出可用图；想看效果自己跑一遍即可。
