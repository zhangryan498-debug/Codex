两个例子。第一个走完整流程，第二个只展示对照——**同一个大类，驱动力不同，主图分配完全不同**，这是本 Skill 与固定模板的核心区别。

> 示例中的产品、参数、价格均为演示用虚构数据。**注意其中没有任何检测报告编号、专利号、销量数字**——这类内容只能来自你的真实资料。

---

## 例 1：完整流程（视觉驱动型 · 手工陶瓷马克杯）

### 输入

```
产品：手工陶瓷马克杯，粗陶质地，哑光釉，350ml
平台：淘宝
人群：25-35 岁女性，喜欢日式/侘寂风家居
价格：89 元
参考：无
资质：普通日用瓷，已有产品质检合格证（编号待提供）
```

### Step 2 输出：驱动力判断

**视觉驱动型。** 依据：陶瓷马克杯的功能差异极小（都能装水），用户决策依据是「好不好看、配不配我的桌面」，不是容量或保温性能。次型为情感价值型（手工感、仪式感），详情页可借用 M3 材质触感模块。

**风格锁：**

| 项 | 设定 |
|---|---|
| 配色 | 主色 燕麦白 #E8E1D5 / 辅助 陶土棕 #A67C52 / 强调 墨黑 #2B2B2B |
| 产品占比 | 主图 55%–70%（视觉驱动型放宽，留氛围空间） |
| 光影 | 侧上方 45° 柔光，弱阴影，模拟清晨窗光 |
| 字体 | 标题思源宋体 Medium／正文思源黑体 Light／数字 DIN |
| 禁漂移 | 高饱和色、亮面反光、科技感元素、渐变背景、任何 logo 水印 |

### 利益翻译表

| Feature | Advantage | Benefit | Evidence |
|---|---|---|---|
| 粗陶胎体 | 表面有颗粒手感 | 握持时有真实的手作触感，不像流水线产品 | 实物微距图 |
| 哑光釉 | 不反光 | 拍照好看，放桌面不抢镜 | 场景图 |
| 350ml | 容量适中 | 一杯咖啡刚好，不用续杯也不会喝不完 | 规格图 |
| 手工拉坯 | 每只略有差异 | 你手上这只是独一无二的 | 多只对比图 |

### 合规边界

普通日用瓷，无特殊功效宣称需求，风险较低。仍须注意：

- 不得使用「最」「唯一」「第一」等绝对化用语——「独一无二」用于描述**手工差异**时需谨慎，改为「每只纹理略有不同」更安全
- 不得宣称「抗菌」「养生」「负离子」等功效（无资质）
- 「食品级」表述需有对应检测报告支撑

> **门 1 暂停**：确认驱动力与风格锁 → 用户确认

### Step 4 输出：主图 Storyboard（视觉驱动型分配）

| # | 任务 | 画面要点 | 禁止 |
|---|---|---|---|
| KV1 | 质感截流 | 杯口至杯身 1/3 微距，颗粒质地占满画面，无文案或仅「手作粗陶」4 字 | 全景、多产品、参数文字 |
| KV2 | 形态全貌 | 三色并排 45° 俯拍，白底，展示完整器型与配色家族 | 场景干扰、道具 |
| KV3 | 场景氛围 | 木质桌面 + 晨光 + 一本书，杯占画面 55%，环境不喧宾夺主 | 杂乱背景、人物抢镜 |
| KV4 | 工艺细节 | 杯底手工落款 + 拉坯纹路特写 | 摆拍感过强 |
| KV5 | 规格行动 | 尺寸标注图 + 350ml + 89 元，数字大于形容词 | 促销红黄配色（与风格锁冲突） |

**⚠️ 注意 KV3 没有做「前后对比」**——视觉驱动型用对比图会把审美品类拉低成功能品类。

### 详情页模块（视觉驱动型必选 + 可选）

`M1 首屏钩子 → M2 核心获益 → M3 材质触感 → M5 场景覆盖 → M7 信任证据 → M10 FAQ → M11 CTA`

共 7 个，在 6–9 区间内。**省略 M4 机制原理、M6 前后对比、M9 竞品对照**——马克杯没有机制可讲，也不存在效果对比。

> **门 2 暂停**：确认任务分配与模块顺序 → 用户确认

### Step 5 输出：KV1 执行稿（节选）

**画面**
杯身左侧 2/3 处斜切构图，微距对焦在釉面颗粒交界处。背景虚化为燕麦白渐隐。光源自右上 45°，在颗粒凸起处形成细密微阴影。视线动线：右上高光 → 颗粒纹理 → 左下杯壁弧线。

**图内文案**
```
手作粗陶
颗粒是留下的手温
```
（2 行，单行 ≤6 字，符合主图约束）

**设计说明**
视觉第一落点在右上高光与颗粒交界，这是质感最强的位置。文案压在左下低对比区，不与质感争夺注意力。燕麦白背景降低刺激度，符合侘寂调性。本图无需免责声明。

**生图 Prompt**
```
macro photograph of handmade matte ceramic mug surface,
coarse stoneware texture with visible clay grain,
oatmeal white #E8E1D5 background softly blurred,
soft window light from upper right 45 degrees,
fine micro-shadows on grain, low contrast, muted palette,
wabi-sabi aesthetic, product occupies 65% of frame,
shot on 100mm macro lens, f/4

negative: glossy reflection, high saturation, gradient background,
tech elements, watermark, logo, text overlay, multiple objects
```

### Step 6：五维自审

```
合规性        88  ✓  未出现绝对化用语；未做功效宣称
利益翻译度    74  ✗  → KV5「350ml」是裸参数，未翻译
                     修改：加「一杯咖啡的量」
              重写后 86 ✓
视觉第一落点  91  ✓  单图单卖点，文案 2 行
触感表达      89  ✓  颗粒/哑光/微阴影已明确
叙事连贯性    83  ✓  5 张分别为质感/形态/场景/工艺/规格，无重复
```

### Step 7：合规风险清单

| 命中内容 | 位置 | 风险类型 | 依据 | 建议处理 |
|---|---|---|---|---|
| 「独一无二」 | 利益翻译表 | 绝对化用语边缘 | 广告法第九条 | 改为「每只纹理略有不同」 |
| 质检证书编号缺失 | M7 信任证据 | 无支撑宣称 | 广告法第二十八条 | 补编号，否则删除该模块 |

## 例 2：对照（同为杯具，痛点驱动型 · 婴儿学饮杯）

同样是杯子，驱动力变了，**主图任务分配完全不同**：

| # | 视觉驱动型（陶瓷马克杯） | 痛点驱动型（婴儿学饮杯） |
|---|---|---|
| KV1 | 质感截流：釉面微距 | 问题截流：宝宝喝水洒一身的场景 |
| KV2 | 形态全貌：三色并排 | 解决过程：重力球随倾斜转动的使用瞬间 |
| KV3 | 场景氛围：晨光书桌 | **前后对比**：倾倒 180° 不漏 vs 普通杯 |
| KV4 | 工艺细节：手工落款 | 安全背书：材质标识 + 适用月龄 |
| KV5 | 规格行动：尺寸价格 | 规格行动：容量 + 配件 + 组合装 |

详情页也不同：马克杯省略 M6 前后对比，学饮杯**必选** M6 和 M7 信任证据。

**合规差异更大。** 婴儿用品属高风险，必须注意：

- 不得宣称「防呛」「防蛀牙」「helps 语言发育」等健康功效（属医疗化暗示，广告法第十七条）
- 材质安全宣称必须附检测报告编号，不得只写「食品级安全材质」
- 不得使用「宝宝专用」暗示医学适应性的表述
- 适用月龄必须与产品实际标注一致

**若无检测报告，按缺资料规则处理：只输出视觉方向和中性文案，不输出任何安全/健康相关表述。**

---

## 从例子里该看到什么

1. **驱动力不是标签，是分配依据**。判断完之后，5 张主图的任务、详情页选哪些模块，都由它决定。
2. **两道门省的是返工**。风格锁在门 1 就定死，后面所有生图 Prompt 都带着它，不会出现第 3 张图突然变风格。
3. **自审的扣分必须能指到位置**。例 1 里「利益翻译度 74」后面跟的是「KV5『350ml』是裸参数」，不是一句「翻译不够充分」。
4. **没有编造任何证据**。检测报告编号缺失就写「缺失」并列进风险清单，不填一个看起来像真的编号。
