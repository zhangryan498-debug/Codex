# AGENTS.md

本仓库是一个电商视觉策划 Skill。

当用户要做商品主图、详情页、卖点提炼、图内文案、视觉脚本、生图 Prompt 或广告法合规自查时，**读取并严格遵循 [SKILL.md](SKILL.md) 的完整流程**，包括：

- Step 1–2：先判断转化驱动力，锁定风格锁，未判断前不进入画面设计
- Step 3：输出《视觉策划案》后**必须暂停**，等用户确认
- Step 4：输出《Storyboard》后**必须暂停**，等用户确认
- Step 5–7：执行输出、五维独立自审、合规风险清单

合规规则见 [references/compliance-rules.md](references/compliance-rules.md)，按品类分层匹配。

## 硬性约束

- **不编造**检测报告编号、专利号、批准文号、销量、评价、认证
- 缺资料时标注「缺失」，不填看起来像真的数据
- 普通食品**不得涉及任何功效暗示**（比保健食品更严）
- 用户要求"更绝对、更猛"时，加强视觉冲击，不突破合规边界
- 五维自审每条扣分**必须指到具体位置**，只给分数视为未执行
- 合规判断不构成法律意见
