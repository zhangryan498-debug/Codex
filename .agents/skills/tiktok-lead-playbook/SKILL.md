# TikTok 出海事业部负责人方法论

本 Skill 是 `tiktok-lead` 的执行手册。**所有方法论以东南亚跨境电商为前提，不可直接套用到抖音侧。**

---

## 1. 岗位定义与考核指标

- **数据通道权威源**是项目 `docs/knowledge/data-channel.md`；取数走项目 `data-pipeline/` 下的采集器。**抖音侧零凭据通道已完全跑通**：热榜（`douyin_public.py`）+ 推荐流/话题真实体量/创作者画像/作品详情/评论（`douyin_feed.py`，推荐流自举，不需要种子 ID、不需要登录、不需要分享链接）。TikTok 侧采集器代码就绪，需 API token。外部数据只用于趋势与竞品判断，**经营口径（结算/真实退货/实收）必须来自店铺后台**。
- **取数三条纪律**：① L0 热榜的 `video_count` / `discuss_video_count` **不是话题体量**，不可当量级证据，只能用于词条间相对热度排序；② 话题真实体量看 `challenge/detail` 的 `view_count` / `user_count`；③ 抖音搜索端点需登录，**「热榜词 → 话题 cid」目前无免登录通道**，垂类批量采样需托管 API 或用户给一条分享链接作种子。

### 岗位定位
TikTok 东南亚出海事业部的经营第一责任人。向上对事业部经营结果负责，向下调度 9 个岗位 Agent，并统筹**跨境链路**（选品↔履约↔合规↔财务）的协同。

### 考核指标
| 维度 | 指标 | 口径要点 |
|---|---|---|
| 规模 | **实际签收 GMV** | 订单 GMV × 实际签收率，**不得直接用订单 GMV** |
| 效率 | **净 ROI** | 扣退货/拒收损耗后。⚠️ 退货只退买家全款，佣金与平台费不退回 |
| 成本 | 佣金成本率 | 平台佣金 + 达人佣金 + 广告佣金分轨核算 |
| 结构 | 分站点贡献 | 印尼/泰国/越南/马来/菲律宾分列，不做跨站平均 |
| 风险 | 签收率 / 拒收率 | 拒收率 >45% 触发限曝光；签收率连续两周 <60% 限制挂车 |
| 现金 | 现金流覆盖月数 | ≥3 个月（COD 回款 12–18 天） |
| 团队 | 9 岗产出按模板交付率 | 流程健康度 |

## 2. 标准作业流程

### 2.1 周度经营循环

| 时段 | 动作 | 产出 |
|---|---|---|
| 周一上午 | 收集 9 岗产出，核对是否按模板交付；未按模板的退回 | 交付齐备度检查 |
| 周一上午 | 拉分站点经营数据（签收 GMV / 净 ROI / 拒收率 / 佣金率 / 现金流覆盖） | 分站点数据底表 |
| 周一下午 | 按 §3 分站点归因顺序走 | 归因结论 |
| 周一下午 | 排本周优先级；**排期必须倒推履约与达人对接周期** | 优先级排序表 |
| 周二 | 派发任务到各岗位 Agent，明确交付物与期限 | 任务派发 |
| 周三/周四 | 跟踪跨岗依赖；插入突发处理 | 进度跟踪 |
| 周五 | 写经营周报，结论先行，**分站点分列** | 周报 |
| 周五下午 | 与内容/选品岗位做 1v1 深谈 | 深度问题清单 |

### 2.2 月度复盘循环

| 步骤 | 内容 |
|---|---|
| 1 | 平台环境变化评估：**分站点**评估费率调整、本地化要求加码、活动日历、本地节庆、站点治理、支付与清关政策 |
| 2 | 分站点货盘结构：类目、价格带、SKU 结构对比上月 |
| 3 | 履约与支付结构：签收率、拒收率、退货率、COD vs 预付占比、现金流覆盖 |
| 4 | 内容与本地化效率：产能、爆款率、本地化复用度 |
| 5 | 达人分销效率：出单达人占比、分层佣金效率、样品投入产出 |
| 6 | 分站预算分配方案 + 佣金策略调整建议 |
| 7 | 下月策略：定 3 个以内核心动作 |

### 2.3 季度策略

定事业部级目标 → **按站点分别拆**（不能一套目标打五站）→ 拆到 9 岗 → 定资源盘子 → 明确"不做什么"。

**季度决策的关键问题**：优先做深一个站点（如印尼），还是铺开做多站点？判断依据是站点费率 × 客单价 × 履约成本 × 本地化成本的乘积结构，不是流量规模。

## 3. 分站点归因决策树

顺序对应"货选对了 → 送得到收得回 → 内容讲得清 → 达人带得动 → 投放赚得回 → 退货控得住"。

```
经营异常（净 ROI 下降 / 签收 GMV 不达预期）
│
├─ 1. 站点与货盘层：选对站点、选对货了吗？
│   ├─ 客单价低于类目基准 → 选品问题：规格/重量/定价策略（→ 选品）
│   ├─ 佣金率高于类目基准 → 达人佣金设太高；>25% 在低客单市场基本不赚钱（→ 选品、投放）
│   ├─ 认证/资质卡住 → 类目认证周期与成本前置不足（→ 选品、美工）
│   └─ 货盘正常 → 继续往下走
│
├─ 2. 履约与支付层：送得到、收得回吗？（★东南亚的胜负手，通常被跳过）
│   ├─ 签收率低 → 查：COD 占比过高？商品描述与实物不符？尺码不合？履约时效超 3-7 天？
│   ├─ 拒收率 >45% → 触发限曝光，必须立即处理（见 §4）
│   ├─ 物流成本占比高 → 重量或仓配结构问题（→ 选品）
│   ├─ 现金流覆盖 <3 个月 → 爆量前必须解决，否则不要放量
│   └─ 履约正常 → 继续往下走
│
├─ 3. 内容与本地化层：讲得清吗？
│   ├─ 播放量低 → 查：本地化是否到位（语言/货币/场景/文化符号）？是否为直译味？
│   ├─ 播放正常但完播低 → 前 3 秒钩子在本地市场是否成立
│   ├─ 限流 → 查：批量克隆同一脚本？盗用素材？AI 换脸？
│   └─ 内容正常 → 继续往下走
│
├─ 4. 达人分销层：达人带得动吗？
│   ├─ 寄样多但出单少 → 佣金设太低或样品/商品不匹配（低佣金换高样品通过率是反向策略）
│   ├─ 达人转化率 <1%（播放 1 万出单 <5） → 受众与商品不匹配，加佣金无用，该换达人
│   ├─ 头部达人不出量 → 佣金未达其预期（同业挖角）
│   └─ 达人正常 → 继续往下走
│
├─ 5. 投放效率层：赚得回吗？
│   ├─ 消耗不动 → 素材量不足/审核不过/账户结构问题（→ 投手）
│   ├─ 表面 ROI 达标但净 ROI 低 → 退货未扣；查退货率与佣金结构
│   └─ 投放正常 → 继续往下走
│
├─ 6. 售后与退款层：退货控得住吗？（★常见主因，却被排到最后）
│   ├─ 退货集中在某 SKU → 规格/描述/尺码问题（→ 美工、选品）
│   ├─ 退货集中在某达人 → 该达人的内容有预期落差（→ 拆解、编导）
│   └─ 退货正常 → 重新审视目标，或存在未识别的外部因素
```

**归因纪律**：东南亚场景下，**"退货"是最高频的真实主因**，但它常被排在最后。走这个树时，第 2 层和第 6 层要花的时间不少于其他层。

## 4. COD 风险处置规则

COD 是东南亚最常见的失控点，单列处置规则。

### 4.1 阈值与后果（硬性，不可协商）

| 指标 | 阈值 | 后果 |
|---|---|---|
| 拒收率 | 连续 7 天 >45% | 限制商品曝光 |
| 拒收率 | 单日 >30% 持续 2 天 | 自动暂停推流 72 小时 |
| 签收率 | 连续两周 <60% | 限制短视频挂车功能 |
| 发货仓 | 非本地认证仓发货 | 判定虚假发货，订单金额 3 倍罚款，最高 $500 |
| 虚假发货 | 连续 3 单 | 冻结账户，已结佣不退 |
| 物流状态 | 48 小时无更新 | 判定虚假发货，扣分至停权 |

### 4.2 处置动作序列

```
发现签收率下滑 / 拒收率上升
│
├─ 立即（24h 内）
│   ├─ 查拒收原因分布：尺码/色差/预期落差/物流时效/买家无意向
│   ├─ 触阈值则先降预算、暂停推流，保护账号权重
│   └─ 复盘近期变更：是否上了新品/改了详情页/换了达人/改了价格
│
├─ 短期（3 天内）
│   ├─ 尺码问题 → 补尺码对照（真人上身 + 尺寸表）、加尺寸对照表视频（实测可降退货约 7%）
│   ├─ 预期落差 → 详情页与口播明确说明；商品页加"实物拍摄"标签；COD 说明写明仅支持货到付款
│   ├─ 物流时效 → 换仓配方案；确认 3-7 天承诺可达
│   └─ 内容端 → 剔除夸大表述；检查 COD 话术是否清晰
│
├─ 中期（两周内）
│   ├─ 调整选品：转向通用规格、重量 <300g、无尺码 S-XXL 通用款
│   ├─ 调整达人：淘汰持续拒收高的达人
│   └─ 调整佣金与定价：重算利润线（含预估退货率）
│
└─ 结构性
    ├─ 提升预付比例（预付退货率 12% vs COD 35-45%）
    ├─ 预付比例提升后回款加快，现金流压力下降
    └─ 用返图赠券等二次销售激励降低损耗（⚠️ 严禁强制捆绑销售，会触发诱导好评违规）
```

### 4.3 现金流纪律

- **爆量前先看现金流，不先看 ROI。** COD 回款 12–18 天，签收后 15 天才回款。
- 现金流覆盖不足 3 个月运营成本时，**放量必须先降节奏**。
- 备货按"下单量"而非"签收量"准备（拒收率 35–45%），且备 ≥15 天销量预估（断货影响推荐权重）。

## 5. 跨平台经验反向转译规范

抖音经验传到东南亚（或反向）时逐条过表。**任何一条不成立，该经验就不可用。**

| 抖音经验要素 | 在东南亚是否成立 | 东南亚的对应做法 |
|---|---|---|
| 投流税上限（多数类目 15%、美妆 30%） | ❌ 不成立 | 东南亚无投流税；改为控制佣金率与广告佣金分离 |
| "仅退款"损耗管理 | ❌ 不成立 | 改为 COD 拒收率与退货率管理（阈值完全不同） |
| 千川账户与全域推广 | ❌ 不成立 | 用 TikTok Ads Manager；优化目标为购买/加购等事件 |
| 商品信息质量分 ≥85 | ❌ 不成立 | 东南亚用商品评分 ≥4.3 + 近 30 天售出 ≥50 件的达人可见门槛 |
| 搜索运营（词库/定坑/热搜词） | ⚠️ 降级 | 搜索心智弱，词库作用是承接内容主动搜索；hashtag 需本地流行 tag，硬翻译无效 |
| 店播是主力（52%） | ❌ 不成立 | 东南亚以联盟分销 + 本地达人批量铺量为主，直播渗透率低 |
| 阶梯升佣冲量 | ⚠️ 需改造 | 改为按站按层设佣金 + 基础佣金/广告佣金分离 |
| 短视频搜索词配置 3 个 | ⚠️ 需改造 | 改为本地 hashtag + 本地语言搜索承接 |
| 内容加载率上限 | ⚠️ 机制不同 | 改为"批量测试需结构差异化，否则限流"（AIGC 识别约 92%） |
| 中文内容与本土达人 | ❌ 不成立 | 四层本地化：语言/货币/场景/文化符号 |
| 618/双11/双12/年货节 | ❌ 不成立 | 用站点活动 + 本地节庆（斋月、开斋节、泼水节、双九、双十、圣诞） |
| 抖音爆品率判断标准 | ❌ 不成立 | 看物流属性、达人可讲性、认证门槛、COD 退货预估 |
| 国内仓次日达 | ❌ 不成立 | 本地仓 3-7 天，超时赔付 10%；COD 必须本地认证仓 |
| 淘宝/拼多多比价货架打法 | ⚠️ 需改造 | 东南亚货架心智未建立，商品卡主要靠内容引流 |

**转译纪律**：转译后的建议必须重新过一遍 §3 的分站点归因树，不要直接照搬对方的优先级。**尤其不能把"退货"排在最后归因**——这在东南亚恰好是最高频的主因。

## 6. 分站点差异速查

| 维度 | 印尼 | 泰国 | 越南 | 马来 | 菲律宾 |
|---|---|---|---|---|---|
| 市场地位 | SEA 最大，MAU 1.25 亿 | 客单较高 | — | 流量约为印尼 1/3 | — |
| 客单价 | $5–15 | $10–30 | $8–20 | 中等 | 中低 |
| 平台佣金（本土店） | 5–8% | 6.42–9.63% | 5–8% | — | — |

## 8. 常见错误与雷区

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 不扣退货算利润 | 表面盈利实则亏损（COD 退货 35–45%，佣金与平台费不退） | 一律用签收 GMV 与净 ROI |
| 把退货归因放最后 | 漏掉真实主因，方向性错误 | 归因树第 2 层和第 6 层重点查 |
| 跨站合并看数据 | 掩盖站点结构差异，误配资源 | 分站点看，不做跨站平均 |
| 直接搬运抖音打法 | 前置条件不成立，损失真金白银 | 逐条过 §5 转译表 |
| 引用旧费率 | 佣金已多次上调，测算全错 | 按当前值复核，标注时点 |
| 忽视签收率阈值 | 触发限曝光/限挂车，账号权重受损 | 每次活动与放量前核对阈值 |
| 用国内仓发 COD | 3 倍罚款最高 $500，判定虚假发货 | 只从本地认证仓发货 |
| 爆量前不看现金流 | 回款断裂（12–18 天） | 覆盖 ≥3 个月，不足则降节奏 |
| 内容未本地化 | 直译味减分，播放起不来 | 四层本地化逐层核验 |
| 批量克隆同一脚本 | 限流（AIGC 识别约 92%） | 结构差异化测试 |
| 佣金设太高不核算 | 印尼低客单下佣金 >25% 不赚钱 | 建联前先算利润线 |
| 佣金设了不改 | 半年后发现从赚变亏 | 每月复盘佣金档位 |
| 所有达人统一佣金 | 头部嫌少、尾部不出量 | 按层设佣金 + 基础/广告佣金分离 |
| 本地化物料缺资金/时间预留 | 节点错过 | 本地节庆提前 6–8 周启动 |

## 9. 数据与规则的时效性规范

- **费率与佣金**：东南亚站点的平台佣金与达人佣金 2026 年已多次上调，**每次输出必须标注来源与时点，并注明需复核**。
- **COD 退货率、拒收率、签收率**：属行业实操区间，随政策与季节波动，标注为区间参考值而非精确值。
- **平台知识库的权威源**是项目 `docs/knowledge/platform-model.md`；与最新平台公告冲突时以平台公告为准，并**立即更新知识库**。
- **站点数据不可跨站套用**：印尼的客单价与费率结构在泰国不成立，任何结论必须限定站点。
