本 Skill 面向抖音选品与货盘运营。**TikTok 侧的 COD 退货预估、跨境物流属性、达人可讲性判定标准完全不同，不可套用本手册。**

### 岗位定位

## 2. 选品评估：五维打分 + 红线先行

用 `templates/选品运营/选品评估表.md`。

### 2.1 抖音侧五维（列组 A）

| 维度 | 关键问题 |
|---|---|
| **内容爆点** | 能否在 3 秒内出效果/冲突 |
| **千川承接性** | 素材是否好投、能否过审 |
| **客单价适配** | 主流 9.9-99 元区间匹配度 |
| **退货风险** | 尺码/色差/预期差 |
| **差评规避** | 材质、功效宣称是否踩线 |

### 2.2 淘汰红线（任一命中即淘汰，不进入测品）
- 售后/仅退款预估吃掉净利 30% 以上
- 功效宣称违反广告法或平台禁限词
- 需强制捆绑销售或诱导好评才能成立
- 素材无法过审 / 禁限类目
- 供应链不稳定（无法承诺备货，断货影响推荐权重）
- 抖音侧：商品信息质量分 <85（自断流量）
- 抖音侧：评分 <4.3 或近 30 天售出 <50 件（达不可见，联盟路径断）

### 2.3 评估纪律
**先过红线，再打分。** 打分是排序工具，不是准入工具。

## 3. 利润测算：必扣两层隐性成本

用 `templates/选品运营/商品利润测算表.md`。

### 3.1 成本项（抖音）

| # | 成本项 | 要点 |
|---|---|---|
| 1 | 售价 | |
| 2 | 商品成本 | |
| 3 | 平台技术服务费 | 按类目；**商品卡免佣活动可减免** |
| 4 | **投流成本** | **受投流税上限约束：多数类目 15%、美妆 30%** |
| 5 | 达人佣金 | 阶梯升佣 10%→20%+ |
| 6 | 物流/包装 | 国内仓 |
| 7 | **退款与"仅退款"损耗** | **必须单独一行** |
| 8 | 其他 | 客服/赠品/样品 |

### 3.2 准入与验证
- **净利率 <15% → 不做**
- **保本 ROI（支付口径）= 1 ÷ (1 − 净利率)** → 投流目标值参考
- **敏感性分析必做**：退货率 +5pct、投流成本上涨、达人佣金 +3pct、售价 -10%
- **盈亏平衡点必算**：退货率到 ____% 时净利归零 / 佣金到 ____% 时归零 / 售价到 ____ 元时归零

### 3.3 为什么"投流税"和"仅退款"必须单独成行
这两项是抖音最容易被漏掉、且漏掉就致命的钱：
- **投流税**：投流费占营收比超过上限（多数类目 15%，美妆 30%）的部分，**在企业所得税下抵扣减少** → 实际投流成本高于账面。ROI 达标不等于赚钱。
- **仅退款**：抖音官方在全员大会上承认退货率是关键短板指标。表面 ROI 达标但被仅退款吃掉 = 假性盈利。

## 4. 测品：标准必须前置

用 `templates/选品运营/测品计划表.md`。

### 4.1 先定义，再测
| 项 | 要求 |
|---|---|
| 观察窗口 | 先定 |
| 成功阈值 | CTR/CVR/ROI/订单数，先定 |
| 失败阈值 | 先定 |
| 淘汰规则 | 先定 |
| **预算止损线** | 先定 |
| 最小样本量 | 先定 |

**没有成功标准的测品是浪费预算。** 这是本岗位最容易犯的低级错误。

### 4.2 抖音三类测品
| 类型 | 看什么 |
|---|---|
| 自然流测款 | 内容起量能力 |
| **千川测款** | **素材可投性（能否过审、能否跑出量）** |
| 达人测款 | 达人可讲性（能否讲清卖点） |

### 4.3 商品确定性 <3 分不排期
库存、价格、合规没解决，拍了也不能上。

## 5. 货盘三件套与生命周期

### 5.1 三件套（JD 明确要求「搭建引流款、利润款、爆款货盘」）

| 角色 | 作用 | 抖音特征 |
|---|---|---|
| **引流款** | 拉停留、破冰成交 | 低门槛、限量、冲销量破 10 单门槛 |
| **利润款** | 承担毛利 | 毛利最高，1-2 个 |
| **爆款** | 承担 GMV | 内容+投流双验证 |

**同时服务两条路**：
- **店播路径（52%）**：要节奏友好、能过款、能憋单
- **达播路径（30%）**：要"可讲性"强——能演示、能对比、能一句话说清卖点

### 5.2 上新节奏与生命周期
JD 明确包含「选品策略、定价、SKU 规划、波段上新节奏、商品生命周期管理」。

分析动作：**畅滞销分析、库存结构分析、库存周转管控、折扣损耗管控、全年库存目标达成**。

### 5.3 货盘交付物
「输出标准化直播货品搭配方案、穿搭组合、套餐模板」「商品周报制作及活动复盘、季度复盘」。

## 7. 常见错误与雷区

| 错误 | 后果 | 正确做法 |
|---|---|---|
| **不测就上大量货** | 滞销吃仓储、折扣损耗、断货影响权重 | 先测品后放量 |
| **利润测算漏掉投流税** | ROI 达标实则亏损 | 单独成行 |
| **利润测算漏掉仅退款** | 假性盈利 | 单独成行 |
| **只测自然流不测千川** | 素材不可投，上量即死 | 三类测品并行 |
| **测品无成功标准** | 预算浪费 | 标准前置 |
| **选"看起来会爆"的品** | 忽略千川承接与退货 | 五维打分 + 红线 |
| **不做 SKU 规划** | 规格不合，退货率飙升 | 通用规格优先 |
| **货盘只有爆款没有引流款** | 直播间留不住人 | 三件套齐备 |
| **忽略商品信息质量分** | 货架与推荐都不给量 | ≥85 门槛前置 |
| **不监控动销与库存** | 断货/滞销两头踩 | 日监控 + 周盘点 |
| **只管自己不管跨部门** | 选完的品落不了地 | 明确到人与交付物 |
| **不输出周月季报** | 无法沉淀 | 固定节奏输出 |
| **套用 TikTok 选品逻辑** | 跨境成本与退货完全没算 | 按平台分别测算 |

## 9. 数据与规则的时效性规范

- **费率、投流税、平台规则**：变动频繁，标注来源与时点，注明需复核。
- **JD 中的门槛值**属岗位市场统计口径，标注来源与统计时点。
- **数据通道权威源**是项目 `docs/knowledge/data-channel.md`；取数走项目 `data-pipeline/` 下的采集器。**抖音侧零凭据通道已完全跑通**：热榜（`douyin_public.py`）+ 推荐流/话题真实体量/创作者画像/作品详情/评论（`douyin_feed.py`，推荐流自举，不需要种子 ID、不需要登录、不需要分享链接）。TikTok 侧采集器代码就绪，需 API token。外部数据只用于趋势与竞品判断，**经营口径（结算/真实退货/实收）必须来自店铺后台**。
- **取数三条纪律**：① L0 热榜的 `video_count` / `discuss_video_count` **不是话题体量**，不可当量级证据，只能用于词条间相对热度排序；② 话题真实体量看 `challenge/detail` 的 `view_count` / `user_count`；③ 抖音搜索端点需登录，**「热榜词 → 话题 cid」目前无免登录通道**，垂类批量采样需托管 API 或用户给一条分享链接作种子。
- **平台知识库权威源**是项目 `docs/knowledge/platform-model.md`；与最新公告冲突以公告为准并立即更新。
- **第三方选品工具数据（蝉妈妈/飞瓜等）为估算**，需标注口径。
- **不确定判断标注置信度**，说明需要谁去验证。
