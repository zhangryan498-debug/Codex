# TikTok 短视频编导方法论

本 Skill 面向 TikTok 东南亚（印尼/泰国/越南/马来/菲律宾）短视频编导场景。

⚠️ **不可套用抖音规则**：抖音的搜索词定坑、黄金 3 秒提法、店播协同、投流税相关的内容策略在东南亚不存在，反之亦然。

---

## 1. 岗位定义与考核指标

### 岗位定位
TikTok 出海内容的**操盘手**。JD 对该岗位的定义与抖音侧同构（编导要"对视频流量、互动、带货转化负责"，且招聘市场上确实存在 TK 编导岗位），但核心挑战是**异国市场的内容接受度**。

### 考核指标

| 指标 | 说明 | 东南亚特有注意点 |
|---|---|---|
| **本地化内容产能** | 日更条数、批量交付能力 | 测试期建议每日 5–8 条 15 秒竖版 |
| **爆款率** | 跑出高于账号中位数的作品比例 | 判定口径与拆解分析专员统一 |
| **签收转化** | 成交且成功签收的比例 | **COD 场景下订单转化 ≠ 真实转化** |
| 本地化通过率 | 四层本地化一次过审比例 | 直译味是主要扣分项 |
| 素材审核通过率 | 合规硬指标 | |
| **素材复用率** | 资产化能力 | MCN 口径核心 |
| **节点内容产出** | 本地节庆的内容覆盖与效果 | 斋月/开斋节等 |

### 硬性任职门槛
- **学历**：本科及以上为主（海外岗对学历要求通常高于国内运营岗）
- **经验**：1–3 年为主；有出海电商/TikTok 内容经验者优先
- **语言**：英语为硬要求；目标站点本地语言为强加分（印尼语/越南语/泰语/马来语）
- **工具**：剪映专业版、PR（+AE/达芬奇加分）；拍摄设备（微单/单反/手机）、稳定器、灯光、收音设备
- **作品集**：**硬性要求且多为明确一票否决**（"简历必须附带作品集……无作品不安排面试"）
- **经验成果**：门槛不是"做过多少条"，而是**"跑通过什么数据"**——CTR、CVR、CPM、千川消耗（TikTok Ads 对应）、播放量
- **跨文化协作**：能与中国总部协同、与本地达人/母语者协作

## 2. 四层本地化核验流程（本手册的核心）

**只做翻译的本地化在东南亚是失败的。** 逐层过：

### 第 1 层：语言
- 口播稿**必须母语者校对**，不得使用机翻或 AI 直译
- 字幕文本同样本地化（不能只本地化口播）
- 术语用当地消费者实际在用的说法（不是教科书翻译）
- **检查项**：本地人念出来会不会觉得"这是翻译的"？会，就重做

### 第 2 层：货币与度量衡
- 金额换算为当地货币，并**注明汇率口径与时点**
- 尺码、重量、容量换算为本地常用单位
- **定价心理适配**：印尼客单价 $5–15、泰国 $10–30——同一商品在不同站要重新定价，不是简单换算

### 第 3 层：场景与模特
- 使用场景符合本地真实生活场景（居家、通勤、菜market、便利店等）
- 模特、肤色、体型符合当地审美与受众
- 道具、包装、背景符合当地习惯
- **禁忌场景**：某些文化背景下的画面禁忌需确认

### 第 4 层：文化符号与梗
- 无中国特有梗、手势、谐音、度量衡笑话
- BGM 选本地流行曲（避免版权问题与文化违和）
- 节日、场景、称呼符合当地语境
- **hashtag 必须本地流行趋势**——硬翻译的 tag 基本无效

### 核验表（拍摄前必须过）

| 层 | 检查项 | 通过标准 | 确认人 |
|---|---|---|---|
| 语言 | 口播稿 | 母语者校对签字 | 本地达人/本地团队 |
| 语言 | 字幕文本 | 与口播一致且本地化 | 本地团队 |
| 货币 | 金额换算 | 已换算 + 注明汇率口径时点 | 运营 |
| 货币 | 单位换算 | 本地常用单位 | 运营 |
| 场景 | 使用场景 | 符合本地真实生活 | 本地团队 |
| 场景 | 模特/审美 | 符合当地审美 | 本地团队 |
| 符号 | 梗与手势 | 无中国特有元素 | 本地团队 |
| 符号 | BGM | 本地流行曲 + 版权可用 | 制作 |
| 符号 | hashtag | 本地流行趋势 | 运营 |

## 3. 批量测试与结构差异化

### 3.1 测试规模
测试期建议**每日 5–8 条 15 秒竖版**。但——

### 3.2 结构差异化规则（硬性）
**批量克隆同一脚本会被限流**（AIGC 识别准确率约 92%）。所以每条测试素材必须记录并区分：

| 差异化维度 | 可选项 |
|---|---|
| 钩子机制 | 痛点场景 / 效果冲击 / 冲突反差 / 悬念 / 原生对话 / 争议观点 / 稀缺 |
| 叙事结构 | 问题-解决 / 对比测评 / 开箱 / 剧情 / 口播讲解 / 街头采访 / 教程 |
| 出镜形式 | 真人口播 / 手部特写 / 产品为主 / 场景演绎 / 前后对比 |
| 节奏 | 快切 / 缓释 / 停顿反转 |
| 时长 | 15s / 25s / 30s |
| BGM 与音效 | 本地流行 / 无音乐 / 环境音 |

**记录在选题库表的"结构差异点"字段**。写不出来的，说明是克隆，必须重做。

### 3.3 归因三分类

| 数据表现 | 归因 | 处理 |
|---|---|---|
| 低播放 + 低转化 | 钩子问题（前置信息太慢） | 自己改前 3 秒 |
| 低播放 + 高转化 | 内容形式有效，钩子需加强 | 改钩子 + 换发布策略 |
| 高播放 + 低转化 | **问题在商品页或人群**，不在内容 | 转交商城运营/投手 |

**东南亚额外注意**：CVR 正常但签收转化低 → 问题在 COD 预期管理与商品描述，不在内容，转交选品与商城运营。

## 4. 达人链路倒推排期

```
选题确定
  ↓ 倒推
样品寄送（考虑国际物流时效）
  ↓
样品审核（3–5 天）
  ↓
合作确认 → 72 小时内排直播或发布
```

**本地节庆（如斋月/开斋节）要提前 6–8 周启动整条链路。** 晚于这个窗口，物料和达人档期都来不及。

排期时必须把这一条写进 `templates/短视频编导/选题库表.md` 与 `templates/短视频编导/素材拍摄清单.md` 的交付期限。

## 5. COD 场景的内容要求

这是东南亚特有的内容职责：

- **内容中必须展示规格与尺寸**（衣服/鞋靴展示上身尺码，商品展示尺寸参照物）
- **明确说明支付方式**（仅支持 COD/货到付款）
- **诚实说明可能存在的差异**（色差、批次）→ 实测可降低拒收率
- 内容里带上尺码对照与尺寸表 → **可降退货约 7%**

**内容降低拒收率，等于直接提高净 ROI。** 这是内容岗在东南亚最直接的业务贡献。

## 7. 常见错误与雷区

| 错误 | 后果 | 正确做法 |
|---|---|---|
| **只做翻译不做本地化** | 直译味减分，播放起不来 | 四层逐层核验，母语者校对 |
| **批量克隆同一脚本** | **限流** | 结构差异化，记录差异点 |
| **硬翻译 hashtag** | 无效流量 | 选本地流行趋势 tag |
| **直接搬抖音钩子套路** | 在当地不成立 | 本地趋势验证后再用 |
| **不展示规格尺寸** | COD 退货率飙升 | 内容展示尺码与尺寸对照 |
| **未标注 AI 生成** | 违规 | 按平台要求标注 |
| **AI 换脸** | 违规 | 绝对禁止 |
| **忽略本地节庆** | 错过最大节点 | 提前 6–8 周启动 |
| **不倒推达人链路时间** | 素材无法上线 | 寄样→审核3-5天→72小时内排期 |
| **只本地化口播不本地化字幕** | 体验割裂 | 字幕同样本地化 |
| **忽略目标国广告法与类目认证** | 下架或罚款 | 上线前合规自检 |
| **不沉淀本地化资产** | 产能无法复制 | 脚本模板/hashtag库/达人素材库 |
| **用国内汇率与定价逻辑** | 价格无竞争力 | 重新定价而非换算 |
| **只看订单转化不看签收** | 误判内容效果 | 看签收转化 |

## 9. 数据与规则的时效性规范

- **平台审核规则、违禁词库、限流策略**：变动频繁，标注来源与时点。
- **本地趋势与流行 BGM/hashtag**：时效性极强，**发布前必须重新确认**，不引用历史结论。
- **爆款判定口径**：与拆解分析专员统一，一经确定不得中途更改。
- **数据通道权威源**是项目 `docs/knowledge/data-channel.md`；取数走项目 `data-pipeline/` 下的采集器。**抖音侧零凭据通道已完全跑通**：热榜（`douyin_public.py`）+ 推荐流/话题真实体量/创作者画像/作品详情/评论（`douyin_feed.py`，推荐流自举，不需要种子 ID、不需要登录、不需要分享链接）。TikTok 侧采集器代码就绪，需 API token。外部数据只用于趋势与竞品判断，**经营口径（结算/真实退货/实收）必须来自店铺后台**。
- **取数三条纪律**：① L0 热榜的 `video_count` / `discuss_video_count` **不是话题体量**，不可当量级证据，只能用于词条间相对热度排序；② 话题真实体量看 `challenge/detail` 的 `view_count` / `user_count`；③ 抖音搜索端点需登录，**「热榜词 → 话题 cid」目前无免登录通道**，垂类批量采样需托管 API 或用户给一条分享链接作种子。
- **平台知识库权威源**是项目 `docs/knowledge/platform-model.md`；与最新公告冲突以公告为准并立即更新。
- **数据口径**：完播率、CTR、CVR、签收转化需与投手、商城运营对齐。
