# D&T 本机海报工作台

内部体验版。支持中国抖音和 TikTok Shop 菲律宾的海报、视频转写和本机岗位检查。海报保留预览、PNG 和分层 PSD 下载，以及按持久文字编号保存下一版。

## 开始体验

在配置过 D&T 的 Windows 电脑双击 `Start-DT-Poster.cmd`。工作台会打开浏览器，默认入口是 `http://127.0.0.1:8735`。保留启动窗口即可使用。关闭窗口停止本机服务。默认数据目录是当前 Windows 用户的 `%LOCALAPPDATA%\DT\PosterWorkbench`。有独立本机客户目录时也可将它作为启动器第一个参数。每个运行实例只访问其启动时选定的目录。Windows 的中文、空格和较长的本机目录可直接使用，任务和作品保留在所选目录。如果启动器提示路径或资料数据库不可用，请缩短文件夹名称或改选更短、可写的本机目录。工作台不会自动搬迁已有文件。启动器会先检查配套 Python、Pillow、Node、PSD 引擎和端口，发现问题时在窗口中提示处理方法。

1. 进入「商品海报」，选中国或菲律宾模拟样例，再点「生成海报」。测试商品和素材均是合成样例。样例文案固定离线运行。
2. 在「任务记录」看进度，在详情打开预览并领取 PNG 和分层 PSD。生成时会保存原图、PSD 和编号图。
3. 在当前版本点「修改文字」，选择该作品的文字编号，填写一至两行文字并保存为新版。界面会提示所选层的行数和字数限制，最终由排版引擎检查实际字形是否放得下。旧版可继续查看和下载。
4. 在「模型设置」选择「自带云端模型」或「Ollama」，填入客户自己的服务地址、模型标识，以及供应商要求的访问令牌。保存设置无需调用模型。「测试连接」会实际请求一次模型。云端测试前会显示发送内容和费用提示。
5. 在任一站点选择获准使用的本机商品图片并填写商品事实。使用云端模式生成海报前，确认接收服务、发送内容和费用。编号修改和文件取回在本机处理。内置双站样例始终在本机演示。

### 云端接口和数据范围

- 填写供应商的 HTTPS API 基础地址，保留其版本路径。例如基础地址为 https://provider.example/v1 时，程序向 /v1/chat/completions 发送一次非流式 POST。若需要认证，供应商须接受 Bearer 令牌。接口和模型需支持 JSON 对象输出以及 max_tokens 参数，并返回完整的 assistant JSON 回包。不同供应商和模型的参数支持可能不同，支持范围以实测为准。
- 测试连接只发送固定短验证提示及模型标识。实际生成发送商品名称、筛选后的商品事实、站点与排版指导。原图、任务记录、模型配置及交付文件保存在各自的本机工作区。
- 云端测试和每次实际生成各发送一次请求，均可能按供应商报价计费。程序不自动重试，费用以供应商账单为准。供应商可能不返回用量，或只返回部分数字。有效的结构化文案仍可使用，工作台会注明用量未知或不完整。无法确认费用或数据发送权限时，可先使用内置样例。
- 可选令牌由 Windows 按当前用户保护保存。地址或模型连接类型变更时，需要重新录入该服务的令牌。服务地址中不得填写访问令牌。供应商需要的专用鉴权、流式或只支持其他端点的服务需单独适配。

## 视频转写与岗位工具

沿用同一个启动器、工作区和任务记录。「视频转写」可导入不超过 24 MiB 的 WAV、MP4、MOV 或 M4A。已部署的本机 FFmpeg 和锁定的 CUDA 语音模型负责处理。支持自动识别以及中文、英语、印尼语和菲律宾语的语言选择。解码音轨最长 5 分钟。完成后从任务记录预览，并下载 JSON、TXT、SRT 与运行回执。损坏文件、无音轨和全零音轨会报错。自动转写仍需审核。

「岗位工具」提供明确站点的离线示例和输入格式。它们调用 D&T 已有的本机检查器，保存输入、结果和状态，可从任务记录取回 JSON。包括派单预检查、选品底价与利润、广告复盘检查、竞品快照或库存复核、商城事实包、活动状态或交接、直播品牌线索、编导字幕时间轴。模拟通过仅覆盖对应本地功能。岗位工具不会发布、投放、报名、派单或访问店铺，也不调用客户模型。

客户自备模型仍从「模型设置」配置，由海报文案流程按原先确认机制调用。各自工作区分别存放配置、任务、媒体与成果。完整岗位推理、客户自备真实模型、真实媒体准确率与实店经营另行验收。

### 本机工作流

「岗位工具」中可执行编导时间线剪辑、直播逐窗账目复盘、活动账本重算、选品价审到商城接收、竞品评价整理、以及负责人派单和回收。按站点选择示例，结果和可取回的交付件保存在同一个本机任务记录。

- 编导剪辑需要授权的同商品 MP4、显式镜头时间点和 SRT。完成后可下载实际 MP4、字幕、时间线和回执。现有引擎不会替客户决定素材真实性或镜头的商业效果。
- 活动账本重算使用项目固定模拟案例。直播、选品和商城的财务或库存结果只在已给证据下计算。未确认字段留待核。
- 负责人工作流按队列依赖先做活动复盘，再跑直播逐窗任务。工作流结束后可看各岗实际计算、任务状态及文件哈希。活动结果不会被拿去签发价格或经营授权。
- 广告多窗口复盘用同站证据计算平台投产、成熟贡献、店铺去重总额与预算余额，保留缺失项和归因限制。
- 短视频拆解从获准的本机 MP4 提取带真实时间戳的帧、总览和复核报告，可选用已有本机语音模型生成字幕草稿。商品身份与字幕准确率仍需另行复核。
- 菲律宾站竞品整理保留真实输入字段的统计口径，菲律宾语、Taglish 和英语语义词频仍待独立验证。本机计算不会替客户做实际商品质量结论。

## 当前范围

- 海报使用已通过的 D&T PSD 引擎和单元素编辑入口。按站点使用对应视觉岗位和原有文案 Skill 的 A/B 方法，实际执行准备、审稿和供稿。首版排版成功后才推进轮换。原生岗位委派和整岗流程仍待验证。
- Ollama 与云端兼容接口均由客户自行配置。云端本轮经本机 HTTPS 协议替身验证，真实模型推理及供应商费用尚待实测。
- 中国与菲律宾样例使用获准的同一张合成几何示意图，模拟站点、商品编号和文案分别标记。演示与模拟协议回包不用于证明真实模型效果。
- 本轮未接真实店铺、发布或投放。新客户端交付物的 Photoshop 应用内重排、跨设备及正式经营不在本机体验范围。
