# D&T 工作区

D&T 是面向中国抖音及 TikTok Shop 菲律宾客户的本机 Agent 工作台。客户导入自己的资料，按需使用自己的模型，由岗位完成内容和分析，人工审校后领回同一版本的文件。发布、实店、预算、账户授权和真人签收是独立阶段。

| 开发线 | 用途 |
| --- | --- |
| `main` | 默认开发线。沿用原改版，支持独立账户目录和三个用途配置。Token Plan 直连关闭。支持新商品海报、主图、商详和同版商城交接的预检 |
| `stable/customer-entry-8775` | 8775 历史原工作台代码。保留既有版本与本机预检记录 |
| `archive/history-filtered` | 旧 Git 的两笔提交经白名单筛选后的历史。新旧提交映射在《归档范围》 |

## 项目入口

1. [AGENTS.md](AGENTS.md) 是现行项目规则。20 岗的定义在 `runtime-agents/`，Codex 岗位在 `.codex/agents/`，权威 Skill 在 `.agents/skills/`。
2. [运行工作台](docs/WORKBENCH.md) 区分稳定版、预览版、运行依赖与本机试验。
3. [验收索引](docs/acceptance/acceptance-index.md) 包含 20 岗、217 个功能和 v16 的 84 个未完整条目。冻结完整离线验收 **133/217**。本机模拟和真人联调各自记账。
4. [归档范围](docs/ARCHIVE-SCOPE.md) 记录各代码来源、保留的历史、排除的本机资料及依赖。

项目不随仓库发模型、凭据、客户图片视频、业务配置、原始回执或数据库。工作台的运行数据放在 Git 之外，或放入工作区中已忽略的 `.local/`。旧工作台及其原任务仍从各自原实例和资料根打开。
