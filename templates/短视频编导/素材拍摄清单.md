## 二、拍摄前准备

### 2.1 脚本与分镜确认
- [ ] 脚本定稿，前 3 秒方案已单独评审
- [ ] 分镜表（镜号/时间/画面/口播/字幕/音效）已打印或共享
- [ ] 口播稿已确认（含禁用词检查）
- [ ] 转化动作与埋点已规划（搜索词/hashtag/挂车位置）

### 2.2 商品与样品
- [ ] 样品已到货，外观/规格/数量核对无误
- [ ] 商品资质与认证文件已备（TikTok 化妆品/食品/电器必备）
- [ ] 尺码/规格样衣齐全（TikTok COD 场景必备）
- [ ] 赠品/道具已备
- [ ] 商品与详情页描述一致性已确认（避免详情不符纠纷）

### 2.3 器材与场地
- [ ] 设备（手机/相机）电量与存储充足
- [ ] 麦克风收音测试通过（⚠️ 音质差直接掉完播）
- [ ] 灯光方案确认（三点光/柔光/反光板）
- [ ] 背景干净、无杂物与品牌露出
- [ ] 场地许可/授权（商用场地、达人拍摄需授权书）

### 2.4 人员与形象
- [ ] 出镜人形象与账号人设一致
- [ ] 服装/妆造符合类目与本地审美（TikTok 需本地化）
- [ ] 手部/指甲/牙齿等细节（美妆类目）
- [ ] 出镜授权书（涉及肖像）

### 2.5 TikTok 本地化准备
- [ ] 口播稿已由本地母语者校对
- [ ] 字幕文本已本地化（非直译）
- [ ] BGM 已选本地流行曲（避免版权与文化违和）
- [ ] 货币与度量衡已换算
- [ ] 场景/道具符合本地生活场景
- [ ] 无中国特有梗/手势/符号

### 2.6 抖音特有准备
- [ ] 素材适配全域推广要求
- [ ] 前 3 秒钩子已准备多个版本（至少 3 个变体）
- [ ] 已规划配合的搜索词 3 个
- [ ] 无违禁词/虚假宣称/仅退款高风险表达

## 六、平台适配自检

**抖音**
- [ ] 素材可直接用于千川投放（适配全域推广）

- [ ] 已考虑 COD 场景的演示清晰度（尺寸/材质要看得清，降低拒收）

- [ ] 素材未被批量克隆（会限流）
- [ ] 规格/尺码有实物呈现
