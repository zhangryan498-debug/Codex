## 四、平台适配

### 抖音
- [ ] 已承接主图的"五槽位"信息，不重复堆砌
- [ ] 有明确的"立即购买"路径，页尾 CTA 清晰
- [ ] 已考虑"仅退款"预期 → 售后说明清晰，避免纠纷
- [ ] 短视频进来的用户需要更快看到卖点 → 卖点前置
- [ ] 主图视频已同步配置（≥6 秒，20-30 秒，竖屏）
- [ ] 尺码对照/细节图已准备（降低退货）
- [ ] 无违规词、无虚假宣称、无盗用素材

### TikTok
- [ ] **全页本地化**：语言、货币、场景、模特、文化符号
- [ ] 货币已换算，注明汇率口径与时点
- [ ] 尺码对照（真人上身 + 尺寸表）——COD 场景降退货关键
- [ ] 尺寸对照表视频是否需要（可降退货约 7%）
- [ ] 类目认证/资质展示已就位（化妆品/食品/电器）
- [ ] 本地退换政策与联系方式已写明（TikTok 客服体系与国内不同）
- [ ] COD 说明已写入（仅支持货到付款 / 支付方式）
- [ ] 适配本地审美（非国内素材直译风格）
- [ ] 无盗用素材、无 AI 换脸；AI 生成按平台要求标注
