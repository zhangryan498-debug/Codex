# 视觉验收清单（前端美工设计师）

> 使用说明：交付前逐项自检，**由设计以外的人复检一遍**。红字项任一不达标不得交付。
> 平台差异分段填写。

## 一、基础规范

- [ ] 尺寸与分辨率符合平台要求
  - 抖音商品卡 1:1；主图视频 ≥6 秒、20-30 秒为宜、竖屏优于横屏
  - TikTok 按目标站点规范（含商品页与直播挂车场景）
- [ ] 色彩模式正确（RGB）、图片体积在限制内
- [ ] 小尺寸/缩略图状态下核心信息仍可读
- [ ] 移动端竖屏阅读体验正常

## 二、内容完整性

- [ ] 五个卖点槽位齐全（特点 / 优势 / 利益点 / 证明 / 场景）
- [ ] 核心卖点唯一、清晰、前置
- [ ] 用户疑虑清单全部有对应解答
- [ ] 规格/尺码信息准确（⚠️ 错尺寸直接放大退货）
- [ ] 价格与优惠信息与实际一致（无虚假划线价）
- [ ] 详情与实物一致（不符会被投诉仲裁，赔付可达订单金额 150%）
- [ ] 资质/认证信息真实且在有效期内

## 三、合规（红字项）

- [ ] 无违禁词、无虚假宣传、无夸大功效
- [ ] 无未授权素材（图片/字体/音乐/模特/视频）
- [ ] 无盗用同行主图
- [ ] 无 AI 换脸他人形象；AI 生成内容按平台要求标注
- [ ] 无诱导好评/诱导分享话术
- [ ] 价格促销不构成价格欺诈
- [ ] 涉及功效宣称的产品有资质支撑

## 四、抖音专项

- [ ] 已适配全域推广场景（商品整体支付 ROI 口径）
- [ ] 主图卖点缩略图可读
- [ ] 利益点中价格机制（如立减）与实际一致
- [ ] 短视频搜索词 3 个已与运营确认并配合配置
- [ ] 商品信息质量分目标 90+，本图已通过质量分校验
- [ ] 已考虑"仅退款"高风险品类的预期管理表达

## 五、TikTok 专项（东南亚）

- [ ] **全页本地化**：语言、货币、场景、模特、审美偏好、文化符号
- [ ] 货币已换算并注明汇率口径与时点
- [ ] 尺码对照已提供（真人上身 + 尺寸表）
- [ ] 尺寸对照表视频是否需要（可降退货约 7%）
- [ ] 类目认证/资质展示已就位（化妆品/食品/电器）
- [ ] 本地退换政策与联系方式已写明
- [ ] COD 说明已写入（货到付款/支付方式）
- [ ] 适配本地审美（非国内素材直译风格）
- [ ] 已被达人可拍摄/可讲解（达人合作场景）

## 六、交付完整性

- [ ] 源文件（PSD/AI）交付
- [ ] 各尺寸切图导出齐全
- [ ] 可编辑文案文案表交付（便于运营自行改）
- [ ] 命名规范统一（便于检索归档）
- [ ] 归档到项目模板库路径
