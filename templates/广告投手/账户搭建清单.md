## 四、自检清单（开跑前逐项打勾）

### 通用
- [ ] 账户余额/授信充足
- [ ] 商品链接可正常访问
- [ ] 落地页加载正常，转化链路可走通
- [ ] 像素/事件回传正常
- [ ] 预算与排期合理，避免首日爆量
- [ ] 已设置单日预算上限与告警
- [ ] 已设置账户级止损规则

### 抖音
- [ ] 未沿用旧的"自然流/付费流"分计划结构
- [ ] 优化目标与结算 GMV 口径对齐
- [ ] 投流费率在投流税上限内（多数类目 15%，美妆 30%）
- [ ] 未超投素材数量导致跑量异常

### TikTok
- [ ] 账户与目标站点匹配（币种、税务主体）
- [ ] 素材已本地化并通过审核
- [ ] Spark Ads 授权有效
- [ ] COD 场景已配置退货率折算的报表口径
- [ ] 现金流能覆盖回款周期（12-18 天）
